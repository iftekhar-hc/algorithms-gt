\section{Non-Convex Function}

In class we assumed function $f$ is convex. This problem considers the non-convex case.
We want to show that for $\beta$-smooth $f$, after $T$ iterations with step size $\eta \le 1/\beta$ we can find a point $x'$ with
$$
\|\nabla f(x')\| \le \sqrt{\frac{2}{\eta \cdot t} (f(x^0) - f(x^*))}.
$$
(Note that for a local optimum we have $\nabla f(x) = 0$, so a small norm $\|\nabla f(x')\|$ indicates that we are close to a local optimum or saddle point.)

    \item Show
    $f(x^{t+1}) \le f(x^t) - \frac{\eta}{2} \|\nabla f(x^t)\|^2$ (Hint: Check the proof from class. Does it work for non-convex functions?)
    \item Show
    $
    \sum_{k=0}^t \|\nabla f(x^k)\|^2 \le \frac{2}{\eta} (f(x^0) - f(x^*))
    $ (Hint: 1.~implies $\frac{\eta}{2} \|\nabla f(x^t)\|^2 \le ...$)
    \item Show
    $
\min_{k=0...t}\|\nabla f(x^k)\| \le \sqrt{\frac{2}{\eta \cdot T} (f(x^0) - f(x^*))}.

\end{enumerate}
where $x^*$ is the global optimum $f(x^*) = \min_x f(x)$.

\section{Greedy Approximation Algorithm}

Consider placing $n$ items into $m$ bins. Item $i$ has weight $w_i$. We want to place these $n$ items into the bins such that the maximum total weight of a bin is minimized. Consider the following greedy
algorithm:\\

Sort the weights $w_i$ in decreasing order. Going through the items in decreasing order of weight, we place each item in the bin with the least current load (as we iterate through the items and place
more items into bins, the least loaded bin may change).
Show this algorithm gives a $1.5-$approximation for the least possible maximum load of any placement of these $n$ items into the $m$ bins.

\section{Hitting Set via Deterministic Rounding}

Let $W=\{w_1, w_2, \ldots, w_n\}$ be a set of positive numbers and let $B_1, B_2, \ldots, B_m$ be subsets of the set $[n]=\{1,2,\ldots, n\}$. We said $H\subseteq [n]$ is a {\it hitting set} if $H\cap B_i\neq \emptyset$ for all $1\leq i\leq m$. Denote by $b=\max |B_j|$ the size of the largest set $B_j,~1\leq j\leq m$. Consider the {\tt Minimum Hitting Set} problem, where we assign weigth $w_i$ to number $i$ and aim to find the hitting set $H$ of minimum weight $\sum_{i\in H} w_i$.\\ 


\begin{enumerate}
    \item Write a LP instance for this problem. Clearly define the variables, objective function, and constraints.
    
    \item Let $x^*$ be a solution of the relaxed LP problem. Consider the deterministic rounding 
    \[
      \hat{x}_i=\begin{cases}
      & 1~\text{if $x^*_i\geq b^{-1}$}\\
      & 0~\text{else}
    \end{cases}
    \]
    Prove that the set $H'=\{i~|~\hat{x}_i=1\}$ is a hitting set.
    \item Show that the deterministic rounding in part (b) yields a $b-$approximation of the {\tt Minimum Hitting Set} problem.
\end{enumerate}
