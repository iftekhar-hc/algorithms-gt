## 1. Executive Summary

This lecture is devoted to the most famous problem in combinatorial optimization and approximation algorithms: the **Traveling Salesman Problem (TSP)**:
1. **Inapproximability of General TSP:** Without the Triangle Inequality, approximating general TSP within *any* polynomial factor $\alpha(n)$ is NP-hard (proved via a one-line reduction from the **Hamiltonian Cycle** problem).
2. **Metric TSP (Undirected + Triangle Inequality):**
   - **The MST Heuristic ($2$-Approximation):** Double the Minimum Spanning Tree, take an Eulerian tour, and shortcut to a TSP tour.
   - **Christofides' Algorithm (1976 — $\frac{3}{2}$-Approximation):** Instead of doubling the entire MST, compute a **Minimum-Cost Perfect Matching $M$ on only the odd-degree vertices $W$ of the MST**! Since $\text{Cost}(\text{MST}) \le \text{OPT}$ and $\text{Cost}(M) \le \frac{1}{2}\text{OPT}$, the Eulerian multigraph $\text{MST} \cup M$ has cost $\le \frac{3}{2}\text{OPT}$.
3. **Asymmetric TSP (Directed + Triangle Inequality):** Why Eulerian tree-doubling fails on directed graphs, and how **Frieze, Galbiati, and Maffioli's (1982) Cycle-Cover Shrinking Algorithm** achieves a $\log_2 n$-approximation via repeated Min-Cost Bipartite Perfect Matching!

## 2. General TSP Is Inapproximable (Unless $\mathbf{P} = \mathbf{NP}$)

### 2.1 Problem Definition
Given a complete undirected graph $G = (V, E)$ on $n$ vertices with non-negative edge costs $c_e \ge 0$, find a **Hamiltonian cycle (TSP tour)**—a simple cycle visiting every vertex in $V$ exactly once—minimizing total cost $\sum_{e \in \text{Tour}} c_e$.

### 2.2 Reduction from Hamiltonian Cycle
> **Theorem:** If $\mathbf{P} \ne \mathbf{NP}$, then for **every** polynomial-time computable factor $\alpha \ge 1$ (even $\alpha = 2^n$), there is no polynomial-time $\alpha$-approximation algorithm for General TSP.

**Proof:** Given an undirected graph $H = (V, E_H)$ in which we want to decide whether a **Hamiltonian Cycle** exists (an NP-complete problem), construct a complete graph $G = (V, E)$ with edge costs:
$$c_e = \begin{cases} 1 & \text{if } e \in E_H \\ \alpha n + 1 & \text{if } e \notin E_H \end{cases}$$
- **If $H$ has a Hamiltonian Cycle:** That cycle is a TSP tour in $G$ using $n$ edges of cost $1$, so $\text{OPT}(G) = n$. Any $\alpha$-approximation algorithm must output a tour of cost $\le \alpha \cdot \text{OPT}(G) = \alpha n$.
- **If $H$ has NO Hamiltonian Cycle:** Every TSP tour in $G$ must use at least one non-edge $e \notin E_H$ of cost $\alpha n + 1$, so **every** tour has cost $\ge (\alpha n + 1) + (n - 1)(1) = (\alpha + 1)n > \alpha n$!
Thus any $\alpha$-approximation algorithm for General TSP would decide Hamiltonian Cycle in polynomial time! $\blacksquare$

## 3. Metric TSP: The MST Heuristic ($2$) and Christofides' Algorithm ($\frac{3}{2}$)

Assume now that $(V, c)$ is **symmetric** ($c_{uv} = c_{vu}$) and satisfies the **Triangle Inequality** ($c_{uw} \le c_{uv} + c_{vw}$).

### 3.1 The MST Heuristic ($2$-Approximation)
- **Lower Bound 1:** Deleting any single edge from an optimal TSP tour $T^*$ leaves a spanning tree of $G$, so:
  $$\text{Cost}(\text{MST}(G)) \le \text{OPT}$$
- **Algorithm:** Compute $T = \text{MST}(G)$, double every edge of $T$ to get an Eulerian multigraph $H$ of cost $2 \cdot \text{Cost}(T) \le 2 \cdot \text{OPT}$, find an Eulerian tour of $H$, and shortcut repeated vertices using the Triangle Inequality to get a TSP tour of cost $\le 2 \cdot \text{OPT}$.

### 3.2 Christofides' Algorithm (1976): $\frac{3}{2}$-Approximation
Why did we double *every* edge of the MST $T$? The only reason $T$ was not Eulerian is that some vertices $W \subseteq V$ had **odd degree** in $T$!
- **Parity Fact (Handshaking Lemma):** In any graph $T = (V, E_T)$, $\sum_{v \in V} \deg_T(v) = 2|E_T|$ is even, so the number of odd-degree vertices $|W|$ is **always even**!
- **Fixing Parity with a Perfect Matching on $W$:** If we add a **perfect matching $M$ on the odd-degree vertices $W$** to $T$, then every vertex $w \in W$ has its degree increased by $+1$ (becoming **even**!), while vertices in $V \setminus W$ keep their even degrees. Thus $H = T \cup M$ is **connected and Eulerian**!

```text
CHRISTOFIDES-ALGORITHM(Metric Complete Graph G = (V, E), costs c):
    1. Compute a Minimum Spanning Tree T of G                       // Cost(T) <= OPT
    2. Let W = {v in V : deg_T(v) is odd}                           // |W| is always even!
    3. Compute a Min-Cost Perfect Matching M on W (non-bipartite!)  // Cost(M) <= OPT / 2
    4. Form Eulerian multigraph H = T U M and find Eulerian tour C  // Cost(C) <= 1.5 * OPT
    5. Shortcut C to a simple TSP tour R visiting each vertex once  // Cost(R) <= 1.5 * OPT
    return R
```

> **Key Lemma 2 (Matching Lower Bound):** For **any** even-sized subset of vertices $S \subseteq V$, the minimum-cost perfect matching $M$ on $S$ has cost at most $\frac{1}{2} \text{OPT}$.

**Proof:** Shortcut the optimal TSP tour $T^*$ of $V$ down to a cycle $C_S$ on $S$ (by the Triangle Inequality, $c(C_S) \le \text{OPT}$). Because $|S|$ is even, $C_S$ is an even-length cycle and decomposes into **two edge-disjoint perfect matchings** $M_{\text{blue}}$ and $M_{\text{red}}$ of $S$ (alternating edges around $C_S$):

```text
          (w_1) ===blue=== (w_2)
           |                 |
          red               red       c(M_blue) + c(M_red) = c(C_S) <= OPT
           |                 |        ==> min(c(M_blue), c(M_red)) <= OPT / 2!
          (w_4) ===blue=== (w_3)
```

Since $c(M_{\text{blue}}) + c(M_{\text{red}}) = c(C_S) \le \text{OPT}$, the cheaper of the two has cost $\le \frac{1}{2}\text{OPT}$, so the minimum-cost perfect matching $M$ on $W$ satisfies $c(M) \le \frac{1}{2}\text{OPT}$. Combining $c(T) \le \text{OPT}$ and $c(M) \le \frac{1}{2}\text{OPT}$ proves **$\text{Cost}(\text{Christofides}) \le \frac{3}{2}\text{OPT}$**! $\blacksquare$

## 4. Asymmetric TSP (ATSP): $\log_2 n$-Approximation via Cycle Covers

### 4.1 Problem Setup & Why Undirected Eulerian Doubling Fails
In **Asymmetric TSP (ATSP)**, $G = (V, E)$ is a complete **directed** graph whose directed edge costs satisfy the directed Triangle Inequality ($c_{uw} \le c_{uv} + c_{vw}$), but symmetry fails ($c_{uv} \ne c_{vu}$, e.g., one-way streets or asymmetric task setup costs).
- Notice we **cannot** simply "double" an arborescence/tree by adding reverse arcs, because reverse arcs $(v, u)$ may have arbitrarily huge cost compared to $(u, v)$!
- Remember: A directed multigraph $H$ is **Eulerian** iff it is strongly connected and every vertex $v$ has **$\text{in-degree}(v) = \text{out-degree}(v)$**.

### 4.2 Minimum-Cost Directed Cycle Cover via Min-Cost Bipartite Matching
> **Definition (Directed Cycle Cover):** A collection of vertex-disjoint directed cycles $C_1, \dots, C_r$ (each of length $\ge 2$) that partitions $V$ (equivalently, every vertex $v \in V$ has in-degree $1$ and out-degree $1$).

- **Polynomial-Time Reduction to Min-Cost Bipartite Perfect Matching (Hungarian Algorithm):**  
  Create a bipartite graph with left side $V_{\text{out}}$ and right side $V_{\text{in}}$ (two copies of $V$), and for every directed arc $(u, v) \in E$ ($u \ne v$), place an edge $(u_{\text{out}}, v_{\text{in}})$ of cost $c_{uv}$. A perfect matching in $V_{\text{out}} \times V_{\text{in}}$ gives every vertex out-degree $1$ and in-degree $1$, which is **literally a directed cycle cover**!
- **Key Lower Bound:** Since any full ATSP tour is itself a cycle cover (with $r = 1$ cycle), the minimum-cost cycle cover on any subset $S \subseteq V$ (by shortcutting $\text{OPT}$ to $S$) has cost **$\le \text{OPT}$**!

### 4.3 The Frieze-Galbiati-Maffioli (1982) Cycle-Shrinking Algorithm
```text
ATSP-CYCLE-SHRINKING(Directed Metric Graph G = (V, E), costs c):
    Initialize S = V,  H = (V, ∅)
    while |S| > 1:
        1. Compute a Min-Cost Directed Cycle Cover C = {C_1, ..., C_r} on S   // Cost(C) <= OPT
        2. Add all directed edges of C to H
        3. From each cycle C_i, keep 1 representative vertex and delete the rest from S
    // H is now a connected Eulerian directed multigraph (in-deg = out-deg at every node)!
    Find an Eulerian tour of H and shortcut repeated vertices to get an ATSP tour
```

- **Analysis ($\log_2 n$-Approximation):**
  1. In each iteration, every cycle $C_i$ has length $\ge 2$, and we keep only $1$ representative vertex per cycle, so **$|S|$ shrinks by at least a factor of $2$** every iteration! Thus the loop runs at most $\log_2 n$ iterations.
  2. Each iteration adds a cycle cover of cost $\le \text{OPT}$ (and preserves $\text{in-deg}(v) = \text{out-deg}(v)$ at every node).
  3. Thus $c(H) \le (\log_2 n) \cdot \text{OPT}$, and shortcutting the Eulerian tour of $H$ produces an ATSP tour of cost **$\le (\log_2 n) \cdot \text{OPT}$**!
