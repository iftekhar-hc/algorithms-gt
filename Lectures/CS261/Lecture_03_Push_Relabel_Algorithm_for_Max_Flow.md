## 1. Executive Summary & Motivation

While augmenting path algorithms (Ford-Fulkerson, Edmonds-Karp, Dinic) maintain **flow conservation** at every step and work toward **disconnecting $s$ from $t$ in $G_f$**, the **Push-Relabel Algorithm** (Goldberg & Tarjan, 1986) flips this paradigm completely on its head:
- It **always maintains $s$-$t$ disconnection in $G_f$** (guided by vertex **heights/labels**).
- It **relaxes flow conservation** into a **preflow** (allowing vertices to temporarily hold **excess flow**) and works locally toward restoring conservation ($e_f(v) = 0$ for all $v \notin \{s, t\}$).

### 1.1 Motivating Bad Example for Augmenting Paths
Consider a broom-shaped graph with a path of $k$ edges of capacity $k$ from $s$ to $x$, followed by $k$ unit-capacity edges from $x$ to $t$:

```text
                                     +---[1]---> (t)
  (s) --[k]--> (v_1) --[k]--> ... -> (x) --[1]--> (t)   (k unit edges)
         path of k edges, cap k      +---[1]---> (t)
```

- **Augmenting Path Algorithms:** Must traverse the $k$-hop stem $k$ separate times, pushing $1$ unit per iteration $\implies \Theta(k^2)$ work.
- **Push-Relabel Intuition:** Flood $k$ units down the stem to $x$ once in $O(k)$ time, then distribute the excess at $x$ across the $k$ unit edges in $O(k)$ time!

## 2. Core Definitions: Preflows, Excess, and Height Functions

### 2.1 Preflow & Excess
A **preflow** $f = \{f_e\}_{e \in E}$ satisfies:
1. **Capacity Constraints:** $0 \le f_e \le u_e$ for all $e \in E$.
2. **Relaxed Conservation (Non-Negative Excess):** For every vertex $v \in V \setminus \{s\}$, total incoming flow is **at least** total outgoing flow:
   $$e_f(v) \triangleq \sum_{e \in \delta^-(v)} f_e - \sum_{e \in \delta^+(v)} f_e \ge 0$$
   Here $e_f(v)$ is called the **excess** at vertex $v$.
   - A vertex $v \in V \setminus \{s, t\}$ with $e_f(v) > 0$ is called **active** (or overflowing).
   - If $e_f(v) = 0$ for all $v \in V \setminus \{s, t\}$, then the preflow $f$ is a valid **flow**!

### 2.2 Height (Label) Function Invariants
To prevent flow from cycling aimlessly and to keep $s$ and $t$ disconnected in the residual network $G_f$, the algorithm maintains a non-negative integer **height** $h(v) \in \mathbb{Z}_{\ge 0}$ for each vertex $v \in V$ satisfying two invariants:

1. **Boundary Pinning Invariant:**
   $$h(s) = n, \qquad h(t) = 0$$
2. **Gradual Downhill Slope Invariant:** For every residual edge $(v, w) \in E_f$ (with positive residual capacity $u_f(v, w) > 0$),
   $$h(v) \le h(w) + 1$$
   *(Equivalently: if $h(v) \ge h(w) + 2$, there cannot be a residual edge from $v$ to $w$!)*

```text
Height h
  n   |  (s) [Pinned at height n]
 n-1  |
  .   |     (v)
  2   |        \   Residual edges can go uphill, flat, or downhill by AT MOST 1 step:
  1   |         ↘  h(v) <= h(w) + 1.  Steep dropoffs (h(v) >= h(w)+2) are FORBIDDEN in G_f!
  0   +------------(t) [Pinned at height 0]
```

### 2.3 Why Height Invariants Guarantee No $s \leadsto t$ Path in $G_f$
> **Lemma (Permanent $s$-$t$ Disconnection):** Any preflow $f$ and height function $h$ satisfying the two height invariants has **no $s \leadsto t$ path in $G_f$**.

**Proof:** Any simple $s \leadsto t$ path in $G_f$ can have at most $n - 1$ edges. Along each edge $(v, w)$ on the path, height can drop by at most $1$ ($h(w) \ge h(v) - 1$). Starting at $h(s) = n$, after at most $n - 1$ hops the height is at least $n - (n - 1) = 1 > 0 = h(t)$, contradiction! $\blacksquare$

> **Corollary (Termination = Optimality):** When no vertex $v \in V \setminus \{s, t\}$ has positive excess ($e_f(v) = 0$), $f$ is a valid flow **and** $G_f$ has no $s \leadsto t$ path—so by the Fundamental Max-Flow Equivalence Theorem, $f$ is guaranteed to be a **maximum flow**!

## 3. The Goldberg-Tarjan Push-Relabel Algorithm

### 3.1 Initialization
1. Set heights: $h(s) = n$, and $h(v) = 0$ for all $v \in V \setminus \{s\}$.
2. Saturate all edges leaving the source: $f_e = u_e$ for all $e \in \delta^+(s)$, and $f_e = 0$ for all other edges.
   *(Why does this satisfy the slope invariant? Because every edge $(s, v)$ out of $s$ is saturated, so $(s, v) \notin E_f$; only backward edges $(v, s) \in E_f$ exist from height $0$ to height $n$, which go uphill!)*

### 3.2 The Two Local Operations: `Push` and `Relabel`
We only ever push flow along **admissible (downhill)** residual edges $(v, w) \in E_f$ where $h(v) = h(w) + 1$:

```text
PUSH-RELABEL(G = (V, E), s, t, u):
    // Initialization
    h(s) = n;  h(v) = 0 for all v != s
    f_(s,v) = u_(s,v) for all (s, v) in δ+(s);  f_e = 0 for all other e in E

    while there exists an active vertex v in V \ {s, t} with excess e_f(v) > 0:
        Pick an active vertex v with MAXIMUM HEIGHT h(v)

        if there is a residual edge (v, w) in G_f with h(v) == h(w) + 1:
            // PUSH operation (route flow 1 step downhill)
            Δ = min(e_f(v), u_f(v, w))
            Augment preflow f on edge (v, w) by Δ
        else:
            // RELABEL operation (all outgoing residual edges go flat or uphill)
            h(v) = h(v) + 1

    return f
```

### 3.3 Why `Push` and `Relabel` Preserve the Height Invariants
- **`Push(v, w)`:** May create a new reverse residual edge $(w, v) \in E_f$. Since we pushed only because $h(v) = h(w) + 1$, the reverse edge satisfies $h(w) = h(v) - 1 \le h(v) + 1$.
- **`Relabel(v)`:** Only executed when $v$ has **no** residual edge to height $h(v) - 1$, meaning every $(v, w) \in E_f$ currently has $h(v) \le h(w)$. Incrementing $h(v) \leftarrow h(v) + 1$ preserves $h(v) \le h(w) + 1$.

## 4. Runtime & Operation Count Analysis ($O(n^3)$)

### 4.1 The Key Structural Lemma (Proved at Start of Lecture 4)
> **Key Lemma:** For any preflow $f$ and any vertex $v$ with positive excess $e_f(v) > 0$, there exists a directed path from $v$ back to $s$ in the residual graph $G_f$.

*(Intuition: Any excess flow sitting at $v$ originated at $s$, so following reverse residual edges of flow-carrying edges traces a path in $G_f$ from $v$ back to $s$.)*

### 4.2 Step 1: Bounding Relabels by $O(n^2)$
- Whenever a vertex $v$ is relabeled, it has positive excess $e_f(v) > 0$.
- By the Key Lemma, there is a simple path $P$ from $v$ to $s$ in $G_f$ of length $|P| \le n - 1$ hops.
- Since each edge on $P$ drops height by at most $1$ and $h(s) = n$:
  $$h(v) \le h(s) + |P| \le n + (n - 1) = 2n - 1$$
- Because each vertex's height starts at $0$, only increases, and never exceeds $2n - 1$:
  $$\text{Relabels per vertex} \le 2n - 1 \implies \text{Total Relabels} \le n(2n - 1) = \mathbf{O(n^2)}$$

### 4.3 Step 2: Bounding Saturating Pushes by $O(mn)$
Every push on $(v, w)$ pushes $\Delta = \min(e_f(v), u_f(v, w))$:
- **Saturating Push ($\Delta = u_f(v, w)$):** Saturates $(v, w)$, deleting $(v, w)$ from $G_f$.
  - For $(v, w)$ to be used again, flow must first be pushed backward on $(w, v)$, which requires $h(w) = h(v) + 1$ (so $h(w)$ must increase by at least $2$). Then to push on $(v, w)$ again, $h(v)$ must increase by at least $2$.
  - Since $h(v), h(w) \le 2n - 1$, each edge undergoes at most $n$ saturating pushes:
    $$\text{Total Saturating Pushes} \le 2m \cdot n = \mathbf{O(mn)}$$

### 4.4 Step 3: Bounding Non-Saturating Pushes by $O(n^3)$ (Highest-Label Rule)
- **Non-Saturating Push ($\Delta = e_f(v) < u_f(v, w)$):** Completely zeroes out the excess at $v$ ($e_f(v) \leftarrow 0$).
- Because the algorithm always selects an active vertex $v$ with **maximum height $H = \max_{x: e_f(x)>0} h(x)$**:
  - As long as **no relabel occurs**, no active vertex ever has height $> H$ (since pushes only move excess downhill to height $H - 1$).
  - Once $v$ (at height $H$) has its excess zeroed out by a non-saturating push, $v$ can **never receive flow again** until the next relabel (because receiving flow requires a push from height $H + 1$, where no active vertices exist!).
  - Thus, between any two consecutive relabels, at most $n$ non-saturating pushes can occur (at most one per vertex):
    $$\text{Total Non-Saturating Pushes} \le n \times (\text{Total Relabels}) = n \cdot O(n^2) = \mathbf{O(n^3)}$$
