## 1. Executive Summary

This lecture resolves the central open question from Lecture 1—*"How do we know when Ford-Fulkerson terminates at a truly maximum flow?"*—by introducing **$(s,t)$-cuts**, proving the **Max-Flow Min-Cut Theorem**, and then addressing Ford-Fulkerson's pseudo-polynomial worst-case runtime via two polynomial-time augmenting path specializations:
1. **Edmonds-Karp Algorithm (1972):** Augment along a **shortest (minimum-hop) path** in $G_f$ via BFS $\implies O(m^2 n)$ time.
2. **Dinic's Algorithm (1970):** Build the **layered graph** $L_f$ and augment along an entire **blocking flow** at once $\implies O(n \cdot T_{\text{blocking}}) = O(m n^2)$ time (or $O(m n \log n)$ with dynamic trees).

## 2. $(s,t)$-Cuts and the Flow-Cut Relationship

### 2.1 Definition of an $(s,t)$-Cut
An **$(s,t)$-cut** is a partition $(A, B)$ of the vertex set $V$ ($A \cup B = V$, $A \cap B = \emptyset$) such that:
$$s \in A \quad \text{and} \quad t \in B$$

Every $(s,t)$-cut buckets the directed edges $E$ into four groups:
1. Edges entirely inside $A$.
2. Edges entirely inside $B$.
3. **Forward cut edges** $\delta^+(A) = \{(u, v) \in E : u \in A, v \in B\}$ (leaving $A$, entering $B$).
4. **Backward cut edges** $\delta^-(A) = \{(u, v) \in E : u \in B, v \in A\}$ (leaving $B$, entering $A$).

```text
         Set A (Source Side)        |        Set B (Sink Side)
    +---------------------------+   |   +---------------------------+
    |   (s) ----> (u)           |   |   |           (w) ----> (t)   |
    |              |  \_________|___|___|_________/  ↑              |
    |              ↓            |   |   |   δ+(A): forward edges    |
    |             (v) <---------|---|---|------------/              |
    |                           |   |   |   δ-(A): backward edges   |
    +---------------------------+   |   +---------------------------+
                                Cut (A, B)
```

### 2.2 Capacity of a Cut & Exact Flow Across a Cut
The **capacity** of an $(s,t)$-cut $(A, B)$ counts **only** the forward edges $\delta^+(A)$:
$$c(A, B) = \sum_{e \in \delta^+(A)} u_e$$

> **Lemma (Net Flow Across Any Cut):** For *any* feasible flow $f$ and *any* $(s,t)$-cut $(A, B)$:
> $$\text{val}(f) = \sum_{e \in \delta^+(A)} f_e - \sum_{e \in \delta^-(A)} f_e$$

**Proof:** By flow conservation, $\sum_{e \in \delta^+(v)} f_e - \sum_{e \in \delta^-(v)} f_e = 0$ for all $v \in A \setminus \{s\}$, and equals $\text{val}(f)$ for $v = s$. Summing over $v \in A$:
- Edges internal to $A$ ($u \in A, w \in A$) contribute $+f_e$ at $u$ and $-f_e$ at $w$, canceling out.
- Edges internal to $B$ contribute $0$.
- Edges in $\delta^+(A)$ contribute $+f_e$, and edges in $\delta^-(A)$ contribute $-f_e$. $\blacksquare$

> **Corollary (Weak Duality):** For any flow $f$ and any $(s,t)$-cut $(A, B)$,
> $$\text{val}(f) = \sum_{e \in \delta^+(A)} \underbrace{f_e}_{\le u_e} - \sum_{e \in \delta^-(A)} \underbrace{f_e}_{\ge 0} \le \sum_{e \in \delta^+(A)} u_e = c(A, B)$$
> Equality $\text{val}(f) = c(A, B)$ holds **iff** every forward edge $e \in \delta^+(A)$ is **saturated** ($f_e = u_e$) and every backward edge $e \in \delta^-(A)$ is **empty** ($f_e = 0$).

## 3. Optimality Conditions & The Max-Flow Min-Cut Theorem

> **Theorem (Fundamental Equivalence / TFAE):** For a flow $f$ in $G$:
> 1. $f$ is a **maximum flow** in $G$.
> 2. There exists an $(s,t)$-cut $(A^*, B^*)$ such that $\text{val}(f) = c(A^*, B^*)$.
> 3. The residual network $G_f$ contains **no $s \leadsto t$ path**.

**Proof:**
- **$(2) \implies (1)$:** Immediate from Weak Duality ($\text{val}(f') \le c(A^*, B^*) = \text{val}(f)$ for all flows $f'$).
- **$(1) \implies (3)$:** Contrapositive: an $s \leadsto t$ path in $G_f$ allows an augmentation yielding a strictly larger flow.
- **$(3) \implies (2)$:** Let $A^* = \{v \in V : s \leadsto v \text{ in } G_f\}$ and $B^* = V \setminus A^*$. Since $t \notin A^*$, $(A^*, B^*)$ is a valid $(s,t)$-cut with no residual edges crossing from $A^*$ to $B^*$. Thus every $e \in \delta^+(A^*)$ has $u_e - f_e = 0 \implies f_e = u_e$, and every $e \in \delta^-(A^*)$ has reverse residual capacity $f_e = 0$. By the Net Flow Lemma, $\text{val}(f) = c(A^*, B^*)$. $\blacksquare$

**Key Consequences:**
- **Max-Flow Min-Cut Theorem (Ford & Fulkerson, 1956):** $\max_f \text{val}(f) = \min_{(A,B)} c(A, B)$ (motivated by Harris & Ross's 1955 RAND study of the Warsaw Pact rail network).
- **Linear-Time Min-Cut Recovery:** Given max flow $f^*$, one BFS/DFS from $s$ in $G_{f^*}$ finds minimum cut $(A^*, V \setminus A^*)$ in $O(m)$ time.

## 4. Polynomial-Time Max Flow: The Edmonds-Karp Algorithm

### 4.1 Why Basic Ford-Fulkerson Can Be Slow
If capacities are large (e.g., $U = 10^9$) and Ford-Fulkerson repeatedly picks long zigzag paths with bottleneck $\Delta = 1$, it can take $\Omega(\text{val}(f^*))$ iterations (**pseudo-polynomial time**).

### 4.2 Edmonds-Karp Specialization (Shortest Augmenting Path)
Instead of picking an arbitrary path in $G_f$, **Edmonds-Karp** runs **Breadth-First Search (BFS)** in $G_f$ and always augments along a **shortest (minimum-hop) $s \leadsto t$ path**.

```text
EDMONDS-KARP(G, s, t, u):
    Initialize f = 0
    while there is an s -> t path in G_f:
        Find a minimum-hop s -> t path P in G_f using BFS   // O(m) time
        Augment f along P by Δ = min_{e in P} u_f(e)
    return f
```

### 4.3 Runtime Analysis ($O(m^2 n)$) via the Layered Graph $L_f$
Let $d(f)$ be the shortest-path hop distance from $s$ to $t$ in $G_f$ (with $d(f) = \infty$ if $t$ is unreachable).

> **Key Lemma:** During Edmonds-Karp:
> 1. **Monotonicity:** $d(f)$ never decreases from one iteration to the next.
> 2. **Strict Progress:** $d(f)$ strictly increases at least once every $m$ iterations.

**Proof via the BFS Layered Graph $L_f$:**
Freeze the BFS layers $V_0 = \{s\}, V_1, V_2, \dots, V_k$ (where $k = d(f)$ and $t \in V_k$) at the start of a phase where the shortest path distance is $k$:

```text
Layer V_0       Layer V_1       Layer V_2             Layer V_k
  [ s ]  =====>  [ u_1 ] =====>  [ v_1 ]  ... =====>   [ t ]
         \       [ u_2 ]         [ v_2 ]
          \....> (sideways / backward edges in G_f cannot help beat k hops)
```

1. **Why $d(f)$ never decreases:** Augmenting along a shortest path $P$ only uses forward layer edges $(V_i \to V_{i+1})$. The only **newly created** residual edges are reverse edges $(V_{i+1} \to V_i)$, which go *backward* one layer! Any path using a backward edge $(V_{i+1} \to V_i)$ needs at least $k + 2$ hops, so the $s \leadsto t$ hop distance can never drop below $k$.
2. **Why $d(f)$ increases within $\le 2m$ augmentations:** Every augmentation saturates at least one **bottleneck edge** $e \in P$, deleting $e$ from $G_f$. As long as $d(f) = k$ remains unchanged, no deleted forward edge $(V_i \to V_{i+1})$ can ever reappear (because reappearing would require pushing flow along $(V_{i+1} \to V_i)$, which cannot lie on any $k$-hop $s \leadsto t$ path!). Since $G_f$ has at most $2m$ edges, after at most $2m$ augmentations all $k$-hop paths are exhausted and $d(f)$ must become $\ge k + 1$.
3. **Total Runtime:** Since $d(f) \in \{1, 2, \dots, n-1, \infty\}$, there are at most $n$ distance phases $\times O(m)$ augmentations per phase $\times O(m)$ BFS time per augmentation $= \mathbf{O(m^2 n)}$.

## 5. Dinic's Algorithm and Blocking Flows

### 5.1 Batching Augmentations on the Layered Graph $L_f$
Instead of running a fresh BFS after every single path augmentation, **Dinic's Algorithm** explicitly constructs the BFS layered graph $L_f$ (retaining only edges from $V_i$ to $V_{i+1}$ for $0 \le i < d(f)$) and finds a **blocking flow** $g$ in $L_f$ in one batch.

> **Definition (Blocking Flow):** A feasible flow $g$ in $L_f$ is a **blocking flow** if every $s \leadsto t$ path in $L_f$ contains at least one saturated edge ($g_e = u_f(e)$). (Equivalently, a blocking flow is where the naive greedy algorithm from Lecture 1 halts!).

```text
DINIC(G, s, t, u):
    Initialize f = 0
    while t is reachable from s in G_f:
        1. Build layered graph L_f from G_f via BFS (keep only V_i -> V_{i+1} edges)
        2. Find a blocking flow g in L_f
        3. Augment f <- f + g
    return f
```

### 5.2 Runtime Comparison of Augmenting Path Algorithms

| Algorithm | Strategy per Phase | Phases / Augmentations | Total Running Time |
| :--- | :--- | :--- | :--- |
| **Ford-Fulkerson** | Arbitrary path in $G_f$ | $\le \text{val}(f^*)$ augmentations | $O(m \cdot \text{val}(f^*))$ (pseudo-poly) |
| **Edmonds-Karp** | Shortest-hop path in $G_f$ | $\le O(mn)$ augmentations | $O(m^2 n)$ |
| **Dinic (DFS Blocking)** | Blocking flow in $L_f$ via DFS | $\le n$ phases $\times O(mn)$ | $O(m n^2)$ |
| **Dinic (Dynamic Trees)** | Blocking flow via Sleator-Tarjan | $\le n$ phases $\times O(m \log n)$ | $O(m n \log n)$ |
