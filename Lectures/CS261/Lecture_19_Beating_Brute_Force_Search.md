## 1. Executive Summary

When an NP-hard problem requires an **exact** solution (no approximation allowed), we do not have to surrender to naive brute-force search! This lecture demonstrates three classic techniques for dramatically beating brute-force exponential search:

| NP-Hard Problem | Naive Brute-Force Time | Exact Algorithm Covered in Lecture 19 | Improved Exact Time |
| :--- | :--- | :--- | :--- |

## 2. Case Study 1: Parameterized $k$-Vertex Cover in $O(m \cdot 2^k)$ Time

### 2.1 Problem Statement
Given an undirected graph $G = (V, E)$ and an integer parameter $k$ (think of $k \approx 15$–$20$ while $n = |V| \approx 10,000$), decide whether $G$ has a vertex cover $S \subseteq V$ of size $|S| \le k$.
- **Naive Brute Force:** Check all $\binom{n}{k} \approx n^k$ subsets of size $k$ $\implies$ completely infeasible for $n = 1,000, k = 15$ ($10^{45}$ subsets!).

### 2.2 Bounded Search Tree (Branching on an Arbitrary Edge)
> **Key Structural Observation:** Pick **any** edge $e = (u, v) \in E$. *Every* valid vertex cover of $G$ **must include $u$ or $v$ (or both)**! Therefore:
> $$\text{$G$ has a vertex cover of size $\le k$} \iff \text{$(G \setminus \{u\})$ or $(G \setminus \{v\})$ has a vertex cover of size $\le k - 1$}$$

```text
   SEARCH-VERTEX-COVER(G, k):
                       [ G, budget k ]
                       Pick any e = (u, v) in E
                          /               \
          Include u in S /                 \ Include v in S
                        ↙                   ↘
            [ G \ {u}, k - 1 ]         [ G \ {v}, k - 1 ]
                   ...                        ...
           (Recursion tree has depth <= k, branching factor 2 ==> <= 2^k leaves!)
```

### 2.3 Pseudocode & Runtime Analysis
```text
HAS-VERTEX-COVER(G = (V, E), k):
    1. Base Cases:
       if E == ∅: return TRUE      // All edges covered!
       if k == 0: return FALSE     // Edges remain, but budget k is exhausted!
    2. Pick an arbitrary edge e = (u, v) in E
    3. Branch:
       Let G_u = G with vertex u and all its incident edges deleted
       Let G_v = G with vertex v and all its incident edges deleted
       return HAS-VERTEX-COVER(G_u, k - 1) OR HAS-VERTEX-COVER(G_v, k - 1)
```
- **Runtime:** The recursion tree has depth at most $k$ and branching factor $2$, so it has at most $2^k$ nodes. Each node does $O(m)$ work to delete incident edges $\implies \mathbf{O(m \cdot 2^k)}$ time!
  *(Because the exponential factor $2^k$ depends **only on the parameter $k$** and the dependence on $n, m$ is linear, $k$-Vertex Cover is **Fixed-Parameter Tractable (FPT)**—solvable in milliseconds for $n = 10,000, k = 20$ since $2^{20} \approx 10^6$!)*

## 3. Case Study 2: Exact Traveling Salesman Problem in $O(n^2 2^n)$ Time

### 3.1 Why Shortest-Path Dynamic Programming Needs Exponential State
In Bellman-Ford (Lecture 1 / CS161), computing shortest walks of $i$ hops requires only $O(n^2)$ states because walks are allowed to repeat vertices. In **TSP**, we must visit **every vertex in $V = \{1, \dots, n\}$ exactly once**, so to avoid repeating a vertex when extending a partial tour by one hop, the subproblem state **must remember the exact subset $S \subseteq V$ of vertices already visited**!

### 3.2 Bellman-Held-Karp Dynamic Programming (1962)
Fix vertex $1$ as the starting point of the tour. For every subset $S \subseteq \{1, \dots, n\}$ with $1 \in S$ and every destination vertex $j \in S$, define:
$$C(S, j) \triangleq \text{minimum cost of a path starting at } 1, \text{ ending at } j, \text{ visiting every vertex in } S \text{ exactly once}$$

- **Base Cases ($|S| = 1$, so $S = \{1\}$):** $C(\{1\}, 1) = 0$ (and $C(S, 1) = +\infty$ for $|S| \ge 2$).
- **Recurrence (Guessing the Penultimate Vertex $k \in S \setminus \{j\}$):**
  $$C(S, j) = \min_{k \in S \setminus \{j\}} \Big\{ C\big(S \setminus \{j\}, k\big) + c_{kj} \Big\}$$
- **Final TSP Tour Cost:** Close the cycle back to vertex $1$:
  $$\text{OPT} = \min_{2 \le j \le n} \Big\{ C\big(\{1, \dots, n\}, j\big) + c_{j1} \Big\}$$
- **Complexity:** There are $\le n \cdot 2^n$ subproblems $(S, j)$, and each takes $O(|S|) = O(n)$ time to evaluate $\implies \mathbf{O(n^2 2^n)}$ time (beating $n!$ enormously: for $n = 30$, $n^2 2^n \approx 10^{12}$ vs. $30! \approx 2.6 \times 10^{32}$!).

## 4. Case Study 3: Schöning's Randomized 3-SAT Algorithm in $O\big((4/3)^n\big)$ Time

### 4.1 The Algorithm (Schöning, 1999 — Extending Papadimitriou's 2-SAT Walk)
Given a 3-CNF formula $\Phi = C_1 \land \dots \land C_m$ over $n$ variables $x_1, \dots, x_n$:

```text
SCHÖNING-3SAT(3-CNF Formula Φ, Outer Repetitions T):
    repeat T times:
        1. Pick a truth assignment a in {True, False}^n uniformly at random
        2. Repeat 3n (or n) inner local steps:
             if a satisfies Φ: return TRUE (and assignment a)
             Pick an arbitrary violated clause C_j = (l_1 v l_2 v l_3)
             Pick one of the 3 variables in C_j uniformly at random (prob 1/3 each)
             Flip that variable's truth value in a
    return FALSE ("Unsatisfiable")
```

### 4.2 Biased 1D Random Walk Analysis on Hamming Distance to $a^*$
Suppose $\Phi$ is satisfiable, and fix a particular satisfying truth assignment $a^* \in \{\text{True}, \text{False}\}^n$. Track the **number of variables on which the current assignment $a$ agrees with $a^*$** (from $0$ up to $n$, where $n$ means $a = a^*$).

```text
  Number of Matching Variables with a*:
  [0] ---> [1] ---> ... ---> [n - k] =======> [n - k + 1] ---> ... ---> [n (Solved!)]
                                |     >= 1/3
                                +-----------> [n - k - 1]
                                      <= 2/3
```

> **Key Observation:** Whenever $a$ violates a clause $C_j$, since $a^*$ satisfies $C_j$, **at least 1 of the 3 literals in $C_j$ must currently disagree with $a^*$**!
> - Therefore, flipping a uniformly random variable from $C_j$:
>   - **Increases** agreement with $a^*$ by $+1$ with probability **$\ge \frac{1}{3}$**!
>   - **Decreases** agreement with $a^*$ by $-1$ with probability **$\le \frac{2}{3}$**.

### 4.3 Three Progressively Tighter Bounds on Single-Trial Success Probability $p$

Suppose the random initial assignment $a$ starts at Hamming distance $k$ from $a^*$ (i.e., $n - k$ matching variables), which happens with binomial probability $\binom{n}{k} 2^{-n}$:

1. **Warmup Bound 1 (Zero Mistakes Allowed Along $k$ Steps — $O\big(\sqrt{3}^n\big) \approx O(1.732^n)$):**
   - If the random initial assignment has $k \le n/2$ disagreements (which happens with probability $\ge \frac{1}{2}$), and in the first $k$ inner steps we pick the right variable every single time, we reach $a^*$ with probability $\ge \frac{1}{2} \left(\frac{1}{3}\right)^{n/2} = \frac{1}{2} (1/\sqrt{3})^n \implies T = O\big((\sqrt{3})^n\big)$.
2. **Bound 2 (Binomial Summation Over All Starting Distances $k$ — $O\big((3/2)^n\big) = O(1.5^n)$):**
   - Summing the "zero mistakes in $k$ steps" probability $(1/3)^k$ over **all** initial distances $k = 0, \dots, n$:
     $$p \ge \sum_{k=0}^n \binom{n}{k} 2^{-n} \left(\frac{1}{3}\right)^k = 2^{-n} \left(1 + \frac{1}{3}\right)^n = \left(\frac{2}{3}\right)^n \quad \implies \quad T = O\left(\left(\frac{3}{2}\right)^n\right)$$
3. **Bound 3 (Allowing $k$ Wrong Steps and $2k$ Right Steps in $3k$ Steps — $O\big((4/3)^n\big) \approx O(1.334^n)$):**
   - Starting at distance $k$ from $a^*$, if during the first $3k$ steps the walk takes **$2k$ steps toward $a^*$** and **$k$ steps away from $a^*$** (net progress $+2k - k = +k$), it reaches $a^*$!
   - By Stirling's approximation ($m! \approx \sqrt{2\pi m} (m/e)^m$), the probability of $2k$ successes (prob $1/3$) and $k$ failures (prob $2/3$) in $3k$ trials is:
     $$\binom{3k}{k} \left(\frac{1}{3}\right)^{2k} \left(\frac{2}{3}\right)^k \approx \frac{\Theta(1)}{\sqrt{k}} \cdot \frac{3^{3k}}{2^{2k}} \cdot \frac{2^k}{3^{3k}} = \frac{\Theta(1)}{\sqrt{k}} \left(\frac{1}{2}\right)^k$$
   - Plugging this into the binomial sum over $k = 0, \dots, n$:
     $$p \ge \frac{\Theta(1)}{\sqrt{n}} \sum_{k=0}^n \binom{n}{k} 2^{-n} \left(\frac{1}{2}\right)^k = \frac{\Theta(1)}{\sqrt{n}} 2^{-n} \left(1 + \frac{1}{2}\right)^n = \frac{\Theta(1)}{\sqrt{n}} \left(\frac{3}{4}\right)^n$$
   - Repeating $T = \Theta\big(\sqrt{n} \ln n \cdot (4/3)^n\big)$ independent trials guarantees success with high probability $1 - 1/n$ in **$\tilde{O}\big((4/3)^n\big)$ time**!
