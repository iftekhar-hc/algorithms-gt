## 1. Executive Summary

This lecture explores the deep synergy between **Linear Programming (LP)** and **Approximation Algorithms**:
1. **Unweighted & Weighted Set Cover ($H_n \le \ln n$ Approximation via Greedy):**
   - **Proof 1 (Piggybacking on Max Coverage):** Running Greedy in phases of $k = \text{OPT}$ iterations shrinks the uncovered universe by $\left(1 - \frac{1}{k}\right)^k \le e^{-1}$ per phase, finishing in $\le k \ln n = \text{OPT} \ln n$ sets.
   - **Proof 2 (Cost-Sharing / Dual Fitting for Weighted Set Cover):** Charging the cost $c_i$ of each chosen set $S_i$ equally among its newly covered elements ($q_e = \frac{c_i}{|S_i^{\text{new}}|}$) and scaling $p_e = q_e / H_n$ produces a **feasible Dual LP solution**, proving $\text{Greedy} \le H_n \cdot \text{OPT}_{\text{LP}} \le H_n \cdot \text{OPT}$!
2. **LP Relaxations & Integrality Gaps:** How relaxing $x_i \in \{0, 1\}$ to $x_i \ge 0$ provides a universal polynomial-time lower bound $\text{OPT}_{\text{LP}} \le \text{OPT}$ for minimization problems.
3. **Two LP-Based $2$-Approximation Algorithms for Weighted Vertex Cover:**
   - **Algorithm 1 (LP Rounding):** Solve the Vertex Cover LP relaxation $x^*$ and round $S = \{v \in V : x_v^* \ge \frac{1}{2}\}$.
   - **Algorithm 2 (Linear-Time Primal-Dual with Approximate Complementary Slackness):** Maintain dual edge prices $p_e \ge 0$, raise prices on uncovered edges until an endpoint becomes tight ($\sum_{e \in \delta(v)} p_e = c_v$), and add tight vertices to $S$—achieving a $2$-approximation in $O(m + n)$ time without solving an LP!

## 2. The Set Cover Problem & Dual-Fitting Analysis

### 2.1 Problem Definition (Weighted Set Cover)
Given a ground universe $U$ of $|U| = n$ elements and subsets $S_1, \dots, S_m \subseteq U$ with non-negative costs $c_1, \dots, c_m \ge 0$, choose a collection $C \subseteq \{1, \dots, m\}$ covering all of $U$ ($\bigcup_{i \in C} S_i = U$) minimizing total cost $\sum_{i \in C} c_i$.

### 2.2 The Greedy Weighted Set Cover Algorithm
At each iteration, let $S_i^{\text{new}} = S_i \setminus (\text{already covered elements})$. Pick the set $S_i$ minimizing the **bang-per-buck (cost per newly covered element)**:
$$i^* = \arg\min_{i : S_i^{\text{new}} \ne \emptyset} \frac{c_i}{|S_i^{\text{new}}|}$$
When $S_{i^*}$ is picked, assign each newly covered element $e \in S_{i^*}^{\text{new}}$ an amortized share $q_e = \frac{c_{i^*}}{|S_{i^*}^{\text{new}}|}$. Clearly:
$$\text{Cost}(\text{Greedy}) = \sum_{e \in U} q_e$$

### 2.3 LP Relaxation, Dual LP, and Dual-Fitting Proof ($H_n \approx \ln n$)

```text
      PRIMAL LP RELAXATION (Set Cover)                DUAL LP (Element Pricing / Packing)
+------------------------------------------+     +------------------------------------------+
| min   sum_{i=1}^m c_i x_i                |     | max   sum_{e in U} p_e                   |
| s.t.  sum_{i : e in S_i} x_i >= 1  (∀ e) | <-> | s.t.  sum_{e in S_i} p_e <= c_i   (∀ i)  |
|       x_i >= 0                     (∀ i) |     |       p_e >= 0                    (∀ e)  |
+------------------------------------------+     +------------------------------------------+
```

> **Key Lemma (Bounding $\sum_{e \in S_i} q_e$ for Any Set $S_i$):** For every set $S_i \in \{S_1, \dots, S_m\}$,
> $$\sum_{e \in S_i} q_e \le c_i \cdot H_{|S_i|} \le c_i \cdot H_n$$
> where $H_k = 1 + \frac{1}{2} + \dots + \frac{1}{k} \le 1 + \ln k$.

**Proof of Key Lemma:** Number the elements of $S_i$ as $e_1, e_2, \dots, e_k$ ($k = |S_i|$) in the **order they are covered by the Greedy algorithm**. Just before $e_j$ is covered, at least the $k - j + 1$ elements $\{e_j, e_{j+1}, \dots, e_k\} \subseteq S_i$ are still uncovered, so choosing $S_i$ itself would have cost-per-new-element at most $\frac{c_i}{k - j + 1}$. Since Greedy picks the minimum cost-per-new-element option at that step:
$$q_{e_j} \le \frac{c_i}{k - j + 1} \quad \implies \quad \sum_{j=1}^k q_{e_j} \le c_i \left(\frac{1}{k} + \frac{1}{k-1} + \dots + \frac{1}{1}\right) = c_i H_k \le c_i H_n$$

**Dual Scaling:** Define $p_e = \frac{q_e}{H_n}$. By the Key Lemma, $\sum_{e \in S_i} p_e \le c_i$ for every $S_i$, so **$p$ is feasible for the Dual LP**! By Weak Duality:
$$\text{Cost}(\text{Greedy}) = \sum_{e \in U} q_e = H_n \sum_{e \in U} p_e \le H_n \cdot \text{OPT}_{\text{LP}} \le H_n \cdot \text{OPT} \quad \blacksquare$$

## 3. Weighted Vertex Cover: LP Rounding vs. Primal-Dual

### 3.1 Problem Definition & LP Relaxation
Given an undirected graph $G = (V, E)$ with vertex costs $c_v \ge 0$, find a subset $S \subseteq V$ containing at least one endpoint of every edge $e = (v, w) \in E$ minimizing $\sum_{v \in S} c_v$.

```text
    PRIMAL LP RELAXATION (Vertex Cover)               DUAL LP (Fractional Edge Matching)
+-----------------------------------------+     +-----------------------------------------+
| min   sum_{v in V} c_v x_v              |     | max   sum_{e in E} p_e                  |
| s.t.  x_v + x_w >= 1   ∀ e = (v,w) in E | <-> | s.t.  sum_{e in δ(v)} p_e <= c_v  (∀ v) |
|       x_v >= 0         ∀ v in V         |     |       p_e >= 0                    (∀ e) |
+-----------------------------------------+     +-----------------------------------------+
```

- **Integrality Gap Example (Triangle $K_3$ with $c_v = 1$):** Any integral vertex cover needs $2$ vertices ($\text{OPT} = 2$), whereas the fractional solution $x_v^* = \frac{1}{2}$ for all $v \in K_3$ is LP-feasible ($0.5 + 0.5 \ge 1$) with cost $1.5$ ($\text{Gap} = 2 / 1.5 = 4/3$, or $2 - 2/n$ on $K_n$).

### 3.2 Algorithm 1: Deterministic LP Rounding ($2$-Approximation)
```text
LP-ROUNDING-VERTEX-COVER(G = (V, E), vertex costs c):
    1. Solve the Primal LP Relaxation to obtain optimal fractional solution x*
    2. Round: return S = {v in V : x*_v >= 1/2}
```
- **Feasibility ($S$ is a valid Vertex Cover):** For every edge $e = (v, w) \in E$, LP feasibility guarantees $x_v^* + x_w^* \ge 1$, so **at least one** of $x_v^*, x_w^*$ must be $\ge \frac{1}{2}$. Thus at least one endpoint is placed in $S$!
- **Approximation Ratio ($\le 2 \cdot \text{OPT}$):** Every vertex $v \in S$ has $1 \le 2 x_v^*$, so:
  $$\sum_{v \in S} c_v \le \sum_{v \in S} c_v (2 x_v^*) \le 2 \sum_{v \in V} c_v x_v^* = 2 \cdot \text{OPT}_{\text{LP}} \le 2 \cdot \text{OPT} \quad \blacksquare$$

## 4. Algorithm 2: Linear-Time Primal-Dual ($2$-Approximation via Approximate Complementary Slackness)

Can we get the same $2$-approximation **without solving a Linear Program**, in $O(m + n)$ linear time? Yes—by relaxing Complementary Slackness by a factor of $2$!

### 4.1 Exact vs. $\alpha$-Approximate Complementary Slackness
For the Vertex Cover Primal-Dual pair $(x, p)$:
- **Exact CS1 (Primal $\implies$ Dual Tight):** $v \in S \; (x_v = 1) \implies \sum_{e \in \delta(v)} p_e = c_v$. *(We maintain this **exactly**!)*
- **Exact CS2 (Dual $\implies$ Primal Tight):** $p_e > 0 \implies x_v + x_w = 1$. *(Impossible in general without solving NP-hard problems!)*
- **$2$-Approximate CS2:** Whenever $p_e > 0$ (in fact, for *every* edge $e = (v, w)$), since $x_v, x_w \in \{0, 1\}$, we trivially have:
  $$x_v + x_w \le 2$$

### 4.2 The Primal-Dual Vertex Cover Algorithm
```text
PRIMAL-DUAL-VERTEX-COVER(G = (V, E), vertex costs c):
    Initialize S = ∅,  and dual prices p_e = 0 for all e in E
    while S is not a valid vertex cover of G:
        1. Pick any uncovered edge e = (v, w) in E  (neither v nor w is in S)
        2. Raise p_e until at least one endpoint v or w becomes Tight:
               Δ = min( c_v - sum_{e' in δ(v)} p_{e'},  c_w - sum_{e' in δ(w)} p_{e'} )
               p_e = p_e + Δ
        3. Add all newly tight vertices (where sum_{e' in δ(u)} p_{e'} == c_u) to S
    return S
```

### 4.3 Two-Line Proof of the $2$-Approximation Guarantee
At termination, $S$ is a valid vertex cover (Primal Feasible), $p$ is Dual Feasible ($\sum_{e \in \delta(v)} p_e \le c_v$ for all $v$), and every $v \in S$ is tight ($\sum_{e \in \delta(v)} p_e = c_v$). Reversing the order of summation:
$$\text{Cost}(S) = \sum_{v \in S} c_v \;\underbrace{=}_{\text{CS1}}\; \sum_{v \in S} \sum_{e \in \delta(v)} p_e = \sum_{e = (v, w) \in E} |S \cap \{v, w\}| \cdot p_e \;\underbrace{\le}_{\text{Approx CS2 } (\le 2)}\; 2 \sum_{e \in E} p_e \;\underbrace{\le}_{\text{Weak Duality}}\; 2 \cdot \text{OPT}_{\text{LP}} \le 2 \cdot \text{OPT} \quad \blacksquare$$
