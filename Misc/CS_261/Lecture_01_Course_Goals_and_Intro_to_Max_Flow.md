## 2. The Maximum Flow Problem: Formal Definition

### 2.1 Problem Input
We are given a directed network $G = (V, E)$ with:
- A designated **source vertex** $s \in V$ (without loss of generality, no incoming edges).
- A designated **sink vertex** $t \in V$ (without loss of generality, no outgoing edges).
- A non-negative **capacity** $u_e \ge 0$ on every directed edge $e \in E$ (assumed integral unless stated otherwise).

### 2.2 Feasible $(s,t)$-Flow
An **$(s,t)$-flow** is an assignment of non-negative real values $\{f_e\}_{e \in E}$ to edges satisfying two families of linear constraints:

1. **Capacity Constraints:** For every edge $e \in E$,
   $$0 \le f_e \le u_e$$
2. **Conservation Constraints (Kirchhoff's Current Law):** For every internal vertex $v \in V \setminus \{s, t\}$, total incoming flow equals total outgoing flow:
   $$\sum_{e \in \delta^-(v)} f_e = \sum_{e \in \delta^+(v)} f_e$$
   where $\delta^-(v)$ denotes edges entering $v$ and $\delta^+(v)$ denotes edges leaving $v$.

### 2.3 Objective Function
Maximize the **value of the flow**, denoted $|f|$ or $\text{val}(f)$, defined as the total flow leaving the source $s$ (which by conservation equals the total flow entering the sink $t$):
$$\max \quad \text{val}(f) = \sum_{e \in \delta^+(s)} f_e = \sum_{e \in \delta^-(t)} f_e$$

### 2.4 Flows vs. Path Decompositions
- **Path view:** Routing flow along discrete $s \leadsto t$ paths (e.g., 3 units along top, 1 unit along zigzag, 1 unit along bottom).
- **Edge-based view (Standard Definition):** Only the aggregate edge values $f_e$ matter. Any assignment satisfying capacity and conservation constraints is a valid flow.

```text
            u              Edge capacities u_e shown in brackets [u_e]
         ↗     ↘           Edge flows f_e shown before slash: f_e / [u_e]
  3/[3] /       \ 2/[2]
       s    1/[3] t        Flow into u: 3.  Flow out of u: 2 (to t) + 1 (to v) = 3.
  2/[2] \   ↓   ↗          Flow into v: 2 (from s) + 1 (from u) = 3.
         ↘     / 3/[3]     Flow out of v: 3 (to t).
            v              Total Flow Value val(f) = 3 + 2 = 5.
```

## 3. Attempt #1: The Naive Greedy Algorithm (and Why It Fails)

### 3.1 The Naive Greedy Strategy
Start with the zero flow $f_e = 0$ for all $e \in E$. Repeatedly search for an $s \leadsto t$ path $P$ in $G$ where every edge $e \in P$ is **unsaturated** ($f_e < u_e$), and push as much flow as possible:
$$\Delta = \min_{e \in P} (u_e - f_e)$$

### 3.2 Counterexample: Getting Stuck in a Blocking Flow
Consider the 4-node network below:

```text
               u
            ↗  |  ↘
     [3]  /    |    \  [2]
        s     [3]    t
     [2]  \    ↓    /  [3]
            ↘  v  ↗
```

Suppose in Iteration 1, BFS/DFS picks the **zigzag path** $P_1 = s \to u \to v \to t$:
- Bottleneck capacity on $P_1$ is $\Delta = \min(3, 3, 3) = 3$.
- We route 3 units along $s \to u \to v \to t$:

```text
               u
            ↗  |  ↘
   3/[3]  /    |    \  0/[2]
        s    3/[3]   t        <-- S-T paths in G with remaining capacity: NONE!
   0/[2]  \    ↓    /  3/[3]      (s->u is full at 3/3; v->t is full at 3/3)
            ↘  v  ↗
```

- **Result of Naive Greedy:** Terminates with $\text{val}(f) = 3$ (a **blocking flow**, which saturates at least one edge on every $s \leadsto t$ path, but is **not** a maximum flow since $\text{OPT} = 5$).

## 4. Idea #2: Residual Graphs & "Undo" Operations (Ford-Fulkerson)

### 4.1 The Key Insight: Allowing Backward ("Undo") Routing
To escape the suboptimal flow of value 3 above, we need to **undo** 2 units of flow on the middle edge $(u, v)$:
- Push 2 units along $s \to v \to u \to t$, where traversing $(v, u)$ backwards **cancels** 2 of the 3 units previously flowing from $u \to v$.

### 4.2 Formal Definition of the Residual Graph $G_f$
Given network $G = (V, E)$ with capacities $u$ and current flow $f$, the **residual network** $G_f = (V, E_f)$ has the same vertex set $V$ and up to two edges for each original edge $e = (v, w) \in E$:

1. **Forward Edge $(v, w)$:** If $f_e < u_e$, include $(v, w)$ with **residual capacity**
   $$u_f(v, w) = u_e - f_e \quad \text{(remaining room to push more flow forward)}$$
2. **Backward Edge $(w, v)$:** If $f_e > 0$, include $(w, v)$ with **residual capacity**
   $$u_f(w, v) = f_e \quad \text{(amount of existing flow we are allowed to undo/cancel)}$$

```text
Original Edge e = (v, w):          Spawns in Residual Graph G_f:
                                          u_e - f_e  (forward)
      f_e / [u_e]                        ---------->
  (v) -----------> (w)              (v)               (w)
                                         <----------
                                            f_e      (backward / undo)
```

### 4.3 Residual Graph Visualization on the Counterexample
After routing 3 units on $s \to u \to v \to t$, the residual graph $G_f$ with positive residual capacities is:

```text
               u
            ↙  ↑  ↘
      3   /    |    \   2
        s      3     t        Augmenting path in G_f:
      2   \    |    /   3     P_2 = s --> v --> u --> t
            ↘  v  ↙           Bottleneck Δ = min(2, 3, 2) = 2!
```

Augmenting along $P_2 = s \to v \to u \to t$ by $\Delta = 2$:
- $(s, v)$: forward edge $\implies f_{sv} \leftarrow 0 + 2 = 2$
- $(v, u)$: **backward edge** for $(u, v)$ $\implies f_{uv} \leftarrow 3 - 2 = 1$
- $(u, t)$: forward edge $\implies f_{ut} \leftarrow 0 + 2 = 2$
- New flow value: $\text{val}(f) = 3 + 2 = 5$ (Optimal!).

## 5. The Ford-Fulkerson Algorithm

### 5.1 Pseudocode

```text
FORD-FULKERSON(G = (V, E), s, t, u):
    Initialize f_e = 0 for all e in E

    while there exists an s -> t path P in residual graph G_f (via BFS or DFS):
        Δ = min_{e in P} u_f(e)          // Residual bottleneck capacity of P
        AUGMENT(f, P, Δ):
            for each edge e in P:
                if e is a forward edge of original edge (v, w) in E:
                    f_(v,w) = f_(v,w) + Δ
                else if e is a backward edge of original edge (w, v) in E:
                    f_(w,v) = f_(w,v) - Δ

    return f
```

### 5.2 Correctness Invariants & Termination (Integral Capacities)

1. **Feasibility Invariant:** At every iteration, $f$ remains a valid flow (satisfies capacity and conservation constraints).
   - *Conservation check at node $v$:* Even when $P$ uses a mix of forward and backward edges incident to $v$ (4 cases: forward-in/forward-out, forward-in/backward-out, backward-in/forward-out, backward-in/backward-out), the net change to $\sum_{e \in \delta^-(v)} f_e - \sum_{e \in \delta^+(v)} f_e$ is identically $0$.
2. **Integrality Invariant:** If all capacities $u_e \in \mathbb{Z}_{\ge 0}$ are integers, then by induction all residual capacities $u_f(e)$ and flow increments $\Delta \ge 1$ are integers at every step.
3. **Termination & Runtime Bound:**
   - Each augmentation increases $\text{val}(f)$ by an integer $\Delta \ge 1$.
   - The maximum possible flow is bounded by $U_{\text{out}}(s) = \sum_{e \in \delta^+(s)} u_e$.
   - Finding a path in $G_f$ and augmenting takes $O(m)$ time (assuming $m \ge n - 1$).
   - **Total Running Time:** $O(m \cdot \text{val}(f^*)) \le O(m \cdot U_{\text{out}}(s))$.

## 6. How Do We Know When We're Done? (Foreshadowing Cuts & Duality)

A central methodological theme of CS261 is the **two-step paradigm for proving optimality**:
1. **Step 1 (Structural):** Identify sufficient **optimality conditions** (certificates that prove no better solution can exist).
2. **Step 2 (Algorithmic):** Design an algorithm that only terminates when those optimality conditions are met.

### 6.1 Motivating Example: Hidden Bottlenecks ("Moats" / Cuts)
Suppose outgoing edges from $s$ have huge capacity ($100 + 1 = 101$) and incoming edges to $t$ have huge capacity ($100 + 1 = 101$), yet the maximum flow is only $3$:

```text
               u  ----[1]----→  w
            ↗  |                ↑  ↘
   [100]  /    |                |    \  [1]
        s    [100]            [100]    t
     [1]  \    ↓                |    /  [100]
            ↘  v  ----[1]----→  z
                   \          /
               ================  <-- Cut (S, T) with S = {s, u, v}, T = {w, z, t}
               Total capacity crossing from S to T = 1 + 1 + 1 = 3!
```

Even though $s$ can send out $101$ units, the **cut** separating $S = \{s, u, v\}$ from $T = \{w, z, t\}$ acts as a "moat" of total forward capacity $1 + 1 + 1 = 3$. Every unit of $s \leadsto t$ flow must cross this cut, so **no flow can exceed 3**.

### 6.2 Fundamental Optimality Claim (Proved in Lecture 2)
> **Claim:** If $f$ is a flow in $G$ such that the residual graph $G_f$ contains **no $s \leadsto t$ path**, then $f$ is a **maximum flow**.
>
> **Corollary:** Because Ford-Fulkerson terminates if and only if $G_f$ has no $s \leadsto t$ path, Ford-Fulkerson is guaranteed to return a maximum flow upon termination.
