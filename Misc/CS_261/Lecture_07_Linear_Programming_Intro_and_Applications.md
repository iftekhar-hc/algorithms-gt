## 2. Formal Definition & Anatomy of a Linear Program

### 2.1 Components of an LP
A **Linear Program** specifies:
1. **Real-valued Decision Variables:** $x = (x_1, x_2, \dots, x_n)^\top \in \mathbb{R}^n$.
2. **Linear Objective Function:** Maximize or minimize a linear combination of the decision variables:
   $$\max \text{ (or } \min\text{)} \quad c^\top x = \sum_{j=1}^n c_j x_j$$
   where $c = (c_1, \dots, c_n)^\top \in \mathbb{R}^n$ are given constants.
3. **Linear Constraints:** A system of $m$ linear inequalities and/or equalities:
   $$\sum_{j=1}^n a_{ij} x_j \le b_i \quad (\text{or } \ge b_i, \text{ or } = b_i) \qquad \text{for } i = 1, \dots, m$$

### 2.2 What Is Allowed vs. Forbidden in an LP

| Feature | Allowed in LP? | Reason / Handling |
| :--- | :---: | :--- |
| $3x_1 - 5x_2 \le 10$, $x_1 + x_2 = 4$ | **Yes** | Linear inequalities ($\le, \ge$) and equalities ($=$) |
| Non-negativity $x_j \ge 0$ or free $x_j \in \mathbb{R}$ | **Yes** | Standard linear bounds |
| Non-linear terms: $x_1^2, \; x_1 x_2, \; \log(x_1), \; |x_1|$ | **No** (directly) | Non-linear (though $\min |z|$ can often be linearized via auxiliary variables!) |
| Strict inequalities: $x_1 < 1$ | **No** | Open sets may have no maximum ($\sup_{x < 1} x = 1$ is not attained) |
| Integrality constraints: $x_j \in \mathbb{Z}$ or $x_j \in \{0, 1\}$ | **No** | Makes the problem an **Integer Linear Program (ILP)**, which is NP-hard! |

## 3. Geometric Intuition of Linear Programming

### 3.1 Concrete 2D Example
Consider maximizing $x_1 + x_2$ subject to $x_1, x_2 \ge 0$, $2x_1 + x_2 \le 1$, and $x_1 + 2x_2 \le 1$:

```text
  x_2
   ^
 1.0 | \ (0, 1)
     |  \
 0.5 |---\ (0, 1/2)
     |    \  \         *(1/3, 1/3) <-- Unique Optimal Corner!
     |     \    \     /                 Objective x_1 + x_2 = 2/3
     |      \      \ /
     |   P   \      * (1/3, 1/3)
     +--------\------\----------------> x_1
   (0,0)    (1/2,0)  (1,0)
```

- **Feasible Region $P$:** Each linear inequality $a_i^\top x \le b_i$ defines a **half-space** in $\mathbb{R}^n$; their intersection $P = \{x \in \mathbb{R}^n : Ax \le b\}$ is a convex **polyhedron** (or **polytope** if bounded).
- **Level Sets of the Objective:** For each target value $z \in \mathbb{R}$, the set $\{x : c^\top x = z\}$ is a hyperplane orthogonal to $c$. Maximizing $c^\top x$ corresponds to sweeping this hyperplane in the direction of $c$ as far as possible while still touching $P$.
- **Corner Optimality Principle:** Whenever an LP has a bounded optimum (and contains a corner/vertex), the optimal value is attained at a **vertex (corner)** of the feasible polyhedron $P$.

### 3.2 The Four Possible Outcomes for an LP
1. **Unique Optimal Solution** (sweeping hyperplane touches a single extreme vertex).
2. **Multiple Optimal Solutions** (sweeping hyperplane is parallel to a face/edge of $P$; convex combinations of optimal vertices are all optimal).
3. **Infeasible** ($P = \emptyset$, e.g., $x_1 \le 1$ and $x_1 \ge 2$).
4. **Unbounded** (objective can be made $+\infty$ for max or $-\infty$ for min, e.g., $\max x_1 + x_2$ subject only to $x_1, x_2 \ge 0$).

## 4. Application 1 & 2: Max Flow and Min-Cost Flow as LPs

### 4.1 Maximum Flow LP
With one decision variable $f_e \in \mathbb{R}$ per edge $e \in E$:
$$\begin{aligned}
\max \quad & \sum_{e \in \delta^+(s)} f_e \\
\text{s.t.} \quad & \sum_{e \in \delta^-(v)} f_e - \sum_{e \in \delta^+(v)} f_e = 0 \qquad \forall v \in V \setminus \{s, t\} \\
& 0 \le f_e \le u_e \qquad \forall e \in E
\end{aligned}$$

### 4.2 Minimum-Cost Flow LP
Adding edge costs $c_e$ and target flow value $d$ requires changing **only two lines** of the LP (unlike combinatorial algorithms, where going from Max-Flow to Min-Cost Flow requires an entirely new algorithm):
$$\begin{aligned}
\min \quad & \sum_{e \in E} c_e f_e \\
\text{s.t.} \quad & \sum_{e \in \delta^+(s)} f_e - \sum_{e \in \delta^-(s)} f_e = d \\
& \sum_{e \in \delta^-(v)} f_e - \sum_{e \in \delta^+(v)} f_e = 0 \qquad \forall v \in V \setminus \{s, t\} \\
& 0 \le f_e \le u_e \qquad \forall e \in E
\end{aligned}$$

## 5. Application 3: Robust Linear Regression ($\ell_1$ vs. $\ell_2$ vs. $\ell_\infty$)

### 5.1 Supervised Linear Regression Setup
Given $m$ labeled data points $(p^{(1)}, \ell_1), \dots, (p^{(m)}, \ell_m)$ where $p^{(i)} \in \mathbb{R}^d$ are feature vectors and $\ell_i \in \mathbb{R}$ are target labels, we want to learn a linear predictor $h(z) = \sum_{j=1}^d a_j z_j + b$ (where the **decision variables** are the slope parameters $a_1, \dots, a_d \in \mathbb{R}$ and intercept $b \in \mathbb{R}$).

The residual error on data point $i$ is $r_i(a, b) = \left| \left(\sum_{j=1}^d a_j p^{(i)}_j + b\right) - \ell_i \right|$.

### 5.2 Comparing Loss Functions: $\ell_2$ (Least Squares) vs. $\ell_1$ (LP)

| Loss / Norm | Objective | Optimization Method | Sensitivity to Outliers |
| :--- | :--- | :--- | :--- |
| **$\ell_2$ (Squared Error)** | $\min \sum_{i=1}^m r_i^2$ | Closed-form Linear Algebra / SVD | **High** (squaring a large outlier error $r_i$ dominates the objective and skews the line) |
| **$\ell_1$ (Absolute Error)** | $\min \sum_{i=1}^m r_i$ | **Linear Programming** | **Robust** (penalizes outliers only linearly!) |
| **$\ell_\infty$ (Min-Max Error)** | $\min \max_{1 \le i \le m} r_i$ | **Linear Programming** | Minimizes worst-case error across all points |

### 5.3 Linearizing the Absolute Value for $\ell_1$ Regression
Because $|z|$ is non-linear, we introduce one auxiliary decision variable $e_i \ge 0$ for each data point $i \in \{1, \dots, m\}$ to upper-bound $\left|\sum_{j=1}^d a_j p^{(i)}_j + b - \ell_i\right|$:
$$\begin{aligned}
\min_{a, b, e} \quad & \sum_{i=1}^m e_i \\
\text{s.t.} \quad & \left(\sum_{j=1}^d a_j p^{(i)}_j + b\right) - \ell_i \le e_i \qquad \forall i = 1, \dots, m \\
& \ell_i - \left(\sum_{j=1}^d a_j p^{(i)}_j + b\right) \le e_i \qquad \forall i = 1, \dots, m
\end{aligned}$$
At optimality, $e_i^* = \left|\sum_{j=1}^d a_j p^{(i)}_j + b - \ell_i\right|$ automatically holds!

## 6. Application 4: Linear Classification & Non-Linear Feature Expansion

### 6.1 Linearly Separable Binary Classification
Given positive examples $P^+ \subset \mathbb{R}^d$ and negative examples $P^- \subset \mathbb{R}^d$, can we find a hyperplane $h(z) = a^\top z + b = 0$ strictly separating $P^+$ from $P^-$?
- Because strict inequalities ($> 0, < 0$) are forbidden in LPs, we use **scale invariance** (scaling $(a, b)$ by a large constant does not change the hyperplane $\{z : a^\top z + b = 0\}$) to normalize the margin to $\pm 1$:
  $$\begin{aligned}
  \sum_{j=1}^d a_j p^{(i)}_j + b \ge +1 \qquad & \forall p^{(i)} \in P^+ \\
  \sum_{j=1}^d a_j p^{(i)}_j + b \le -1 \qquad & \forall p^{(i)} \in P^-
  \end{aligned}$$

### 6.2 Non-Linear Boundaries via Feature Expansion (Precursor to Kernels)
What if $P^+$ and $P^-$ are separated by a **quadratic curve** (e.g., an ellipse or parabola) rather than a straight line?
- Since the data coordinates $p^{(i)}$ are **fixed constants** (not decision variables!), we can preprocess each $p \in \mathbb{R}^d$ via a non-linear feature map $\Phi: \mathbb{R}^d \to \mathbb{R}^{d'}$, such as degree-2 monomials:
  $$\Phi(z_1, \dots, z_d) = \big(z_1, \dots, z_d, \; z_1^2, \dots, z_d^2, \; z_1 z_2, \dots, z_{d-1} z_d\big) \in \mathbb{R}^{d'}$$
- A **linear hyperplane in feature space $\mathbb{R}^{d'}$**, $\sum_{k=1}^{d'} a_k \Phi(z)_k + b = 0$, is linear in the decision variables $(a, b)$ (so it is still solved by a standard LP!), while corresponding to a **quadratic decision boundary** in the original space $\mathbb{R}^d$!
