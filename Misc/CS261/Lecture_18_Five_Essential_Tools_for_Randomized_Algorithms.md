## 1. Executive Summary

This lecture presents the **Five Essential Probabilistic Tools** that every algorithm designer and machine learning researcher needs for analyzing randomized algorithms, illustrated through MAX-3SAT, load balancing in hash tables, and Raghavan-Thompson **Randomized LP Rounding** for Disjoint Paths:
1. **Tool #1 — Linearity of Expectation:** $\mathbb{E}\left[\sum_{i} X_i\right] = \sum_{i} \mathbb{E}[X_i]$ holds **with zero independence assumptions**! Used to prove that a uniformly random truth assignment gives a $\frac{7}{8}$-approximation for **MAX-3SAT**.
2. **Tool #2 — Markov's Inequality:** $\Pr[X \ge c \cdot \mathbb{E}[X]] \le \frac{1}{c}$ for any non-negative random variable $X \ge 0$. Used to convert expected-value guarantees into high-probability guarantees via repeated trials, and to bound single-bin hash loads under minimal (marginal uniformity) assumptions.
3. **Tool #3 — Chebyshev's Inequality:** $\Pr\big[|X - \mathbb{E}[X]| \ge t \cdot \sigma\big] \le \frac{1}{t^2}$ using variance $\text{Var}(X)$. Since $\text{Var}\left(\sum_{i} X_i\right) = \sum_{i} \text{Var}(X_i)$ requires only **pairwise independence**, Chebyshev yields a $O(1/n^2)$ tail bound for universal (pairwise independent) hash families.
4. **Tool #4 — Chernoff Bounds:** Exponentially decaying tail bounds $\Pr[X > (1 + \delta)\mu] \le \left(\frac{e^\delta}{(1+\delta)^{1+\delta}}\right)^\mu$ for sums of **fully independent** bounded random variables $X = \sum_{i} X_i \in [0, 1]$.
5. **Tool #5 — The Union Bound:** $\Pr\left[\bigcup_{i=1}^k \mathcal{E}_i\right] \le \sum_{i=1}^k \Pr[\mathcal{E}_i]$ (no independence needed!). Paired with Chernoff bounds, it proves that hashing $n$ balls into $n$ bins has max load $O(\frac{\log n}{\log \log n})$ with high probability, and powers **Randomized Rounding of Multicommodity Flow LPs** (Raghavan & Thompson, 1987).

## 2. Tool #1: Linearity of Expectation & Johnson's $\frac{7}{8}$-Approximation for MAX-3SAT

### 2.1 Linearity of Expectation
For **any** random variables $X_1, \dots, X_m$ on the same probability space (**whether independent or arbitrarily correlated!**):
$$\mathbb{E}\left[\sum_{j=1}^m X_j\right] = \sum_{j=1}^m \mathbb{E}[X_j]$$

### 2.2 Application: Randomized $\frac{7}{8}$-Approximation for MAX-3SAT
- **Input:** $m$ clauses $C_1, \dots, C_m$ over Boolean variables $x_1, \dots, x_n \in \{\text{True}, \text{False}\}$, where each clause $C_j = (\ell_{j,1} \lor \ell_{j,2} \lor \ell_{j,3})$ has $3$ distinct variables.
- **Algorithm:** Set each variable $x_i$ to $\text{True}$ or $\text{False}$ **independently and uniformly at random** with probability $\frac{1}{2}$.
- **Analysis:** Let $X_j \in \{0, 1\}$ be the indicator that clause $C_j$ is satisfied. Clause $C_j$ is falsified **only** if all $3$ of its literals evaluate to False, which happens with probability $\left(\frac{1}{2}\right)^3 = \frac{1}{8}$. Thus $\mathbb{E}[X_j] = \Pr[C_j \text{ satisfied}] = 1 - \frac{1}{8} = \frac{7}{8}$.
  By **Linearity of Expectation** (even though clauses share variables and $X_1, \dots, X_m$ are heavily dependent!):
  $$\mathbb{E}[\text{Total Clauses Satisfied}] = \mathbb{E}\left[\sum_{j=1}^m X_j\right] = \sum_{j=1}^m \mathbb{E}[X_j] = \frac{7}{8} m \ge \frac{7}{8} \text{OPT}$$
  *(Remarkably, by **Håstad's Theorem (1997)**, achieving $\frac{7}{8} + \epsilon$ for MAX-3SAT in polynomial time is NP-hard!)*

## 3. Tools #2, #3, #4, #5: Concentration Inequalities & The Hashing Hierarchy

Consider hashing a subset $S \subseteq U$ of $|S| = n$ elements into $n$ buckets $\{1, \dots, n\}$. Fix a bucket $i$ and let $X = \sum_{y \in S} X_y$ be the load of bucket $i$, where $X_y \in \{0, 1\}$ indicates $h(y) = i$.

```text
  |                                         |   | + Tool #5: Union Bnd |   | 3 ln n / ln ln n w.h.p.) |
  +-----------------------------------------+   +----------------------+   +--------------------------+
```

### 3.1 Tool #2: Markov's Inequality
> **Theorem (Markov):** If $X \ge 0$ is a non-negative random variable and $c > 0$, then
> $$\Pr\big[X \ge c \cdot \mathbb{E}[X]\big] \le \frac{1}{c}$$

- **Application 1 (Turning Expectation into High Probability in MAX-3SAT):** Let $Y = m - \sum_{j=1}^m X_j \ge 0$ be the number of *unsatisfied* clauses ($\mathbb{E}[Y] = \frac{1}{8}m$). By Markov, $\Pr\big[Y \ge \frac{1}{8}m(1 + 8\epsilon)\big] \le \frac{1}{1 + 8\epsilon} \approx 1 - 8\epsilon$, so each random assignment satisfies $\ge (\frac{7}{8} - \epsilon)m$ clauses with probability $\ge 8\epsilon$!
- **Application 2 (Hashing under P1 Only):** With $\mathbb{E}[X] = n \cdot \frac{1}{n} = 1$, Markov gives $\Pr[X \ge n] \le \frac{1}{n}$ (which is tight if $\mathcal{H}$ consists of the $n$ constant hash functions $h_k(y) \equiv k$!).

---

### 3.2 Tool #3: Chebyshev's Inequality & Pairwise Independence
> **Theorem (Chebyshev):** For any random variable $X$ with finite mean $\mu = \mathbb{E}[X]$ and standard deviation $\sigma = \sqrt{\text{Var}(X)}$, and any $t > 0$:
> $$\Pr\big[|X - \mu| \ge t \cdot \sigma\big] \le \frac{1}{t^2}$$
> *(Proof: Apply Markov's Inequality to the non-negative random variable $Z = (X - \mu)^2$ with $c = t^2$.)*

- **Crucial Property:** If $X_1, \dots, X_n$ are **pairwise independent** ($\Pr[X_y = a \land X_z = b] = \Pr[X_y = a]\Pr[X_z = b]$ for all $y \ne z$), then all covariances $\text{Cov}(X_y, X_z) = 0$, so **variances still add linearly**:
  $$\text{Var}\left(\sum_{y \in S} X_y\right) = \sum_{y \in S} \text{Var}(X_y) = n \cdot \frac{1}{n}\left(1 - \frac{1}{n}\right) \le 1 \quad \implies \quad \sigma \le 1$$
- Applying Chebyshev with $t \approx n$ gives $\Pr[X \ge n] \le \frac{1}{n^2}$ for any universal (pairwise independent) hash family!

### 3.3 Tool #4 (Chernoff Bounds) & Tool #5 (Union Bound)
> **Theorem (Chernoff Bound for Upper Tail):** Let $X = \sum_{y=1}^n X_y$ be a sum of **mutually independent** random variables $X_y \in [0, 1]$, with $\mu = \mathbb{E}[X]$. Then:
> - For any $\delta > 0$:
>   $$\Pr\big[X > (1 + \delta)\mu\big] \le \left(\frac{e^\delta}{(1 + \delta)^{1 + \delta}}\right)^\mu$$
> - For small $\delta \in (0, 1]$: $\Pr\big[X > (1 + \delta)\mu\big] \le e^{-\delta^2 \mu / 3}$ (and $\Pr\big[X < (1 - \delta)\mu\big] \le e^{-\delta^2 \mu / 2}$).

> **Theorem (Tool #5 — The Union Bound):** For **any** events $\mathcal{E}_1, \dots, \mathcal{E}_k$ (**no independence required!**):
> $$\Pr\left[\bigcup_{i=1}^k \mathcal{E}_i\right] \le \sum_{i=1}^k \Pr[\mathcal{E}_i]$$

- **Max Load of $n$ Balls in $n$ Bins:** For a single bin $i$ ($\mu = 1$), setting $1 + \delta = c = \frac{3 \ln n}{\ln \ln n}$ in the Chernoff bound gives:
  $$\Pr[\text{Load}(i) > c] \le \frac{e^{c-1}}{c^c} \le \left(\frac{e}{c}\right)^c \le \frac{1}{n^2}$$
  Applying the **Union Bound** over all $n$ bins $\mathcal{E}_1, \dots, \mathcal{E}_n$ gives:
  $$\Pr\left[\max_{1 \le i \le n} \text{Load}(i) > \frac{3 \ln n}{\ln \ln n}\right] \le \sum_{i=1}^n \Pr[\text{Load}(i) > c] \le n \cdot \frac{1}{n^2} = \frac{1}{n} \to 0$$

## 4. Application: Randomized LP Rounding for Edge-Disjoint Paths (Raghavan & Thompson, 1987)

- **Problem:** Given a directed graph $G = (V, E)$ and $k$ terminal pairs $(s_1, t_1), \dots, (s_k, t_k)$, select one $s_i \leadsto t_i$ path $P_i$ for each commodity $i \in \{1, \dots, k\}$ minimizing the **maximum edge congestion** (number of selected paths sharing any edge $e \in E$).
- **LP Relaxation (Multicommodity Flow):** Check if there is a fractional multicommodity flow routing $1$ unit from each $s_i$ to $t_i$ such that every edge $e \in E$ carries total fractional flow $\sum_{i=1}^k f_{i, e} \le 1$.
- **Randomized Rounding Algorithm:**
  1. Decompose each commodity $i$'s 1 unit of fractional flow into a convex combination of $s_i \leadsto t_i$ paths $\mathcal{P}_i$ with weights $\{f_P\}_{P \in \mathcal{P}_i}$ ($\sum_{P \in \mathcal{P}_i} f_P = 1, \; f_P \ge 0$).
  2. **Independently for each commodity $i \in \{1, \dots, k\}$**, interpret $\{f_P\}_{P \in \mathcal{P}_i}$ as a probability distribution over $\mathcal{P}_i$ and sample **one path $P_i \sim \{f_P\}$**!
- **Chernoff + Union Bound Analysis:**
  - Fix any edge $e \in E$, and let $X_{i, e} \in \{0, 1\}$ indicate whether commodity $i$'s sampled path $P_i$ uses edge $e$.
  - By construction, $\mathbb{E}[X_{i, e}] = \sum_{P \in \mathcal{P}_i : e \in P} f_P = f_{i, e}$, so the expected congestion on edge $e$ is:
    $$\mu_e = \mathbb{E}\left[\sum_{i=1}^k X_{i, e}\right] = \sum_{i=1}^k f_{i, e} \le 1$$
  - Since choices $X_{1, e}, \dots, X_{k, e}$ are **mutually independent across commodities $i = 1, \dots, k$**, the exact same Chernoff bound as in Balls-into-Bins shows $\Pr\left[\sum_{i=1}^k X_{i, e} > \frac{3 \ln m}{\ln \ln m}\right] \le \frac{1}{m^2}$.
  - Taking a **Union Bound** over all $m = |E|$ edges proves that with probability $\ge 1 - \frac{1}{m}$, **every edge is used by at most $O\left(\frac{\log m}{\log \log m}\right)$ paths**!
