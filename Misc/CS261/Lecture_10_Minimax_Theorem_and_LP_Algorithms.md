## 1. Executive Summary

This lecture concludes the Linear Programming module with two major topics:
1. **Von Neumann's Minimax Theorem (1928) via Strong LP Duality:** Proving that in any finite two-player zero-sum game $A \in \mathbb{R}^{m \times n}$, committing to an optimal mixed strategy first carries **zero first-mover disadvantage**:
   $$\max_{x \in \Delta_m} \min_{y \in \Delta_n} x^\top A y = \min_{y \in \Delta_n} \max_{x \in \Delta_m} x^\top A y$$
2. **Algorithms for Linear Programming:**
   - **The Simplex Method (Dantzig, 1947):** Vertex-to-vertex local search along edges of the feasible polytope; exponential worst-case time (Klee-Minty cube) but blazingly fast in practice.
   - **The Ellipsoid Method (Shor, Nemirovski, Yudin; Khachiyan, 1979):** First polynomial-time LP algorithm; solves LPs with **exponentially many constraints** in polynomial time provided a polynomial-time **Separation Oracle** exists.
   - **Interior Point Methods (Karmarkar, 1984):** Best of both worlds—worst-case polynomial time and competitive with Simplex in practice.

## 2. Two-Player Zero-Sum Games & The Minimax Theorem

### 2.1 Game Setup (Payoff Matrix $A \in \mathbb{R}^{m \times n}$)
- **Row Player** chooses row $i \in \{1, \dots, m\}$; **Column Player** chooses column $j \in \{1, \dots, n\}$.
- Entry $a_{ij}$ is the payoff **Row Player receives from Column Player** in outcome $(i, j)$ (so Row maximizes $a_{ij}$ and Column minimizes $a_{ij}$).

**Example: Rock-Paper-Scissors ($3 \times 3$ Payoff Matrix):**
$$A = \begin{pmatrix} 0 & -1 & +1 \\ +1 & 0 & -1 \\ -1 & +1 & 0 \end{pmatrix} \begin{array}{l} \text{(Rock)} \\ \text{(Paper)} \\ \text{(Scissors)} \end{array}$$

### 2.2 Mixed Strategies and Expected Payoff
Let $\Delta_m = \{x \in \mathbb{R}_{\ge 0}^m : \sum_{i=1}^m x_i = 1\}$ and $\Delta_n = \{y \in \mathbb{R}_{\ge 0}^n : \sum_{j=1}^n y_j = 1\}$ be probability distributions (**mixed strategies**) over rows and columns. If Row plays $x \in \Delta_m$ and Column plays $y \in \Delta_n$ independently, the expected payoff to the Row Player is:
$$\mathbb{E}[\text{Payoff}] = \sum_{i=1}^m \sum_{j=1}^n x_i y_j a_{ij} = x^\top A y$$

### 2.3 Going First vs. Going Second
1. **Row Moves First (Commits to $x \in \Delta_m$), Column Best-Responds:**
   - Once $x$ is announced, Column can achieve $\min_{y \in \Delta_n} x^\top A y = \min_{j \in \{1, \dots, n\}} (x^\top A)_j$ (since a linear function over $\Delta_n$ is minimized at a pure column $j$).
   - Row chooses $x \in \Delta_m$ to maximize this worst-case guarantee:
     $$v_{\text{row-first}} = \max_{x \in \Delta_m} \min_{y \in \Delta_n} x^\top A y = \max_{x \in \Delta_m} \min_{1 \le j \le n} \sum_{i=1}^m a_{ij} x_i$$
2. **Column Moves First (Commits to $y \in \Delta_n$), Row Best-Responds:**
   - Once $y$ is announced, Row can achieve $\max_{x \in \Delta_m} x^\top A y = \max_{i \in \{1, \dots, m\}} (Ay)_i$.
   - Column chooses $y \in \Delta_n$ to minimize this worst-case loss:
     $$v_{\text{col-first}} = \min_{y \in \Delta_n} \max_{x \in \Delta_m} x^\top A y = \min_{y \in \Delta_n} \max_{1 \le i \le m} \sum_{j=1}^n a_{ij} y_j$$

> **Theorem (Von Neumann's Minimax Theorem, 1928):** For every payoff matrix $A \in \mathbb{R}^{m \times n}$,
> $$\max_{x \in \Delta_m} \min_{y \in \Delta_n} x^\top A y = \min_{y \in \Delta_n} \max_{x \in \Delta_m} x^\top A y \triangleq V^* \quad (\text{the Value of the Game})$$

### 2.4 Proof of the Minimax Theorem via Strong LP Duality
Encode the Row-First problem ($\max_{x \in \Delta_m} \min_{1 \le j \le n} \sum_{i=1}^m a_{ij} x_i$) as a Linear Program by introducing a single unconstrained scalar variable $v \in \mathbb{R}$ representing the worst-case payoff across all columns $j$:

```text
   PRIMAL LP (Row Player Moves First)             DUAL LP (Column Player Moves First)
+----------------------------------------+     +----------------------------------------+
| max   v                                |     | min   w                                |
| s.t.  v - sum_i a_ij x_i <= 0   (∀ j)  | <-> | s.t.  w - sum_j a_ij y_j >= 0   (∀ i)  |
|       sum_{i=1}^m x_i     = 1          |     |       sum_{j=1}^n y_j     = 1          |
|       x_i >= 0,  v in ℝ (free)         |     |       y_j >= 0,  w in ℝ (free)         |
+----------------------------------------+     +----------------------------------------+
   Dual multipliers: y_1..y_n >= 0, w in ℝ        Primal multipliers: x_1..x_m >= 0, v in ℝ
```

- Look at the **Dual LP**:
  - The $n$ inequality constraints $v - \sum_{i=1}^m a_{ij} x_i \le 0$ get non-negative dual variables $y_1, \dots, y_n \ge 0$.
  - The equality constraint $\sum_{i=1}^m x_i = 1$ gets an unrestricted dual variable $w \in \mathbb{R}$.
  - The free primal variable $v \in \mathbb{R}$ (with objective coefficient $1$) yields the dual equality constraint $\sum_{j=1}^n y_j = 1$!
  - Each primal variable $x_i \ge 0$ (with objective coefficient $0$) yields the dual constraint $w - \sum_{j=1}^n a_{ij} y_j \ge 0 \iff w \ge \sum_{j=1}^n a_{ij} y_j$ for all $i = 1, \dots, m$.
- Thus the Dual LP minimizes $w = \max_{1 \le i \le m} \sum_{j=1}^n a_{ij} y_j$ over $y \in \Delta_n$, which is **literally the Column-First problem**!
- Both LPs are always feasible (e.g., $x_i = 1/m, v = \min_{i,j} a_{ij}$), so **Strong LP Duality** immediately implies $v_{\text{row-first}} = v_{\text{col-first}} = V^*$! $\blacksquare$

*(Bonus Connection: Just as Strong LP Duality implies the Minimax Theorem, the Minimax Theorem also implies Strong LP Duality—a fact proved algorithmically in Lectures 11–12 via Multiplicative Weights!)*

## 3. Algorithms for Linear Programming: Simplex, Ellipsoid, and Interior Point

### 3.1 The Simplex Method (George Dantzig, 1947)
- **Geometric Idea:** Since an LP over a bounded polytope always attains its optimum at a **vertex (corner)**—a point where $n$ linearly independent defining inequalities hold with equality—Simplex performs **local search on the vertices** along the edges of the polytope.
- **Neighboring Vertices:** Two vertices are adjacent if they share $n - 1$ tight constraints (swapping one tight constraint out and one new tight constraint in moves along a 1D edge of the polytope).
- **Why Local Optimality Implies Global Optimality:** Because the feasible region $P$ is **convex** and the objective $c^\top x$ is **linear**, any vertex that is at least as good as all of its neighboring vertices is **globally optimal**!
- **Duality View of Simplex:** Simplex maintains **Primal Feasibility** and **Complementary Slackness** at all times, and works toward **Dual Feasibility** (terminating with an explicit dual certificate of optimality!).
- **Complexity (Theory vs. Practice):**
  - **Practice:** Visits only $O(m + n)$ vertices on almost all real-world instances; commercial solvers (CPLEX, Gurobi) routinely solve LPs with $10^5$–$10^6$ variables/constraints.
  - **Worst-Case Theory (Klee-Minty Cube, 1972):** By slightly squashing the $n$-dimensional hypercube $[0, 1]^n$, one can force standard pivot rules to visit **all $2^n$ vertices**!
  - **Open Problem (Hirsch Conjecture / Polynomial Simplex):** Whether there exists any pivot rule for Simplex that guarantees a polynomial number of steps in the worst case remains unknown; however, **Smoothed Analysis (Spielman & Teng, 2001)** proved that under tiny Gaussian perturbations of $A$, Simplex runs in polynomial time!

### 3.2 The Ellipsoid Method (Khachiyan, 1979) & Separation Oracles
- **Historical Milestone:** Resolved the longstanding open question by proving that **Linear Programming is in $\mathbf{P}$** (polynomial time in the bit-complexity of the input).
- **How It Works ("Catching a Lion in the Sahara"):**
  1. Reduce optimization to **feasibility** via binary search on the objective value $c^\top x \ge \tau$.
  2. Start with a huge ellipsoid $E_0$ guaranteed to contain the feasible polytope $P$.
  3. Query whether the current ellipsoid center $z_k$ is feasible ($z_k \in P$):
     - If $z_k \in P$: Done! Return $z_k$.
     - If $z_k \notin P$: Obtain a **violated constraint** $a_i^\top x \le b_i$ (where $a_i^\top z_k > b_i$), which cuts the ellipsoid $E_k$ in half ($P$ lies entirely in the half-ellipsoid $\{x \in E_k : a_i^\top x \le a_i^\top z_k\}$).
  4. Enclose that half-ellipsoid in a new, smaller ellipsoid $E_{k+1}$ whose volume shrinks by a factor of $\approx e^{-1/(2n)}$ per step, and repeat until either a feasible point is found or the volume drops below the minimum possible volume of a full-dimensional rational polytope.

```text
          Step k: Query center z_k of Ellipsoid E_k
                    _.--------------._
                 .-'        |         '-.
               .'   P       |  * z_k     '.      Separation Oracle returns
              /  [feasible] | (infeasible) \     violated halfspace a_i^T x <= b_i.
              \   region    |              /     Wrap left half-ellipsoid in a
               '.           |            .'      smaller ellipsoid E_{k+1}!
                 '-.________|_________.-'
```

- **Superpower of Ellipsoid — Exponentially Many Constraints via a Separation Oracle:**
  Notice the Ellipsoid Method never looks at the full list of constraints up front! It only needs a **Separation Oracle**:
  > **Definition (Separation Oracle):** Given candidate point $z \in \mathbb{R}^n$, either certify that $z \in P$ or return a single violated inequality $a_i^\top x \le b_i$ with $a_i^\top z > b_i$.
  - **Example (Dual of Path Max-Flow LP):** Has $n = |E|$ variables $\ell_e$ and **exponentially many** path constraints $\sum_{e \in P} \ell_e \ge 1$. Given candidate edge lengths $\ell$, how do we check if all paths have length $\ge 1$ in polynomial time? Run **Dijkstra's Algorithm** in $O(m + n \log n)$ time! If the shortest $s \leadsto t$ path $P^*$ has length $< 1$, return $P^*$ as the violated constraint!

### 3.3 Interior Point Methods (Karmarkar, 1984)
Instead of walking along the boundary corners like Simplex, **Interior Point Methods** traverse through the **strict interior** of the polytope $P$ by adding a logarithmic **barrier penalty** $-\mu \sum_{i} \ln(b_i - a_i^\top x)$ to the objective (keeping the iterate away from the boundary walls) and gradually decaying $\mu \to 0$ using Newton steps:
- **Best of Both Worlds:** Provably polynomial-time in the worst case **and** competitive with (often faster than) Simplex on massive sparse LPs in practice!

| Algorithm | Trajectory | Worst-Case Time | Practical Speed | Can Solve Exponential Constraint LPs? |
| :--- | :--- | :--- | :--- | :--- |
| **Simplex (1947)** | Boundary vertices/edges | Exponential ($2^n$) | **Extremely Fast** | No (column generation heuristics exist) |
| **Ellipsoid (1979)** | Shrinking outer ellipsoids | **Polynomial** | Very Slow | **Yes (via Separation Oracle!)** |
| **Interior Point (1984)** | Central path in interior | **Polynomial** | **Extremely Fast** | No |
