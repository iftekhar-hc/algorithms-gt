## 1. Executive Summary

This lecture demonstrates how the **Multiplicative Weights Update (MWU)** online learning algorithm serves as a fast, lightweight offline meta-algorithm for solving zero-sum games, linear classification, and structured Linear Programs (such as Maximum Flow and Multicommodity Flow):
1. **Two Useful Extensions of MWU:**
   - Competing against any **mixed distribution $p^* \in \Delta_n$** in hindsight (automatic by linearity).
   - Scaling to arbitrary reward ranges **$r_a^{(t)} \in [-M, +M]$** (requiring $T = O(\frac{M^2 \ln n}{\epsilon^2})$ rounds to achieve additive regret $\le \epsilon$).
2. **Application 1 — Computing Approximate Minimax Optimal Strategies:** Pitting an MWU Row Player against a Best-Response Column Player computes $2\epsilon$-optimal mixed strategies $(\hat{x}, \hat{y})$ in $O(\frac{\ln m}{\epsilon^2})$ iterations.
3. **Application 2 — Linear Classification with Margin $\epsilon$ (Perceptron / Winnow):** Using MWU over the $d$ feature coordinates where an **Oracle** feeds a violated data point each round finds a separating hyperplane in $O(\frac{M^2 \ln d}{\epsilon^2})$ rounds.
4. **Application 3 — Fast Approximate Maximum Flow via MWU + Dijkstra:** Formulating Max-Flow / Fractional Min-Cut as a zero-sum game between an Edge Player (MWU) and a Path Player (Dijkstra shortest-path best response) computes a $(1-\epsilon)$-approximate maximum flow by simply averaging $T$ shortest paths!

## 2. Two Extensions of the Multiplicative Weights Guarantee

### 2.1 Extension 1: Competing Against Any Mixed Strategy $p^* \in \Delta_n$
Since MWU's expected total reward satisfies $\sum_{t=1}^T \gamma_t \ge \sum_{t=1}^T r_a^{(t)} - R_T$ for **every** pure action $a \in A$, taking a convex combination with weights $p_a^* \ge 0$ ($\sum_{a \in A} p_a^* = 1$) immediately yields:
$$\sum_{t=1}^T \gamma_t = \sum_{a \in A} p_a^* \left(\sum_{t=1}^T \gamma_t\right) \ge \sum_{a \in A} p_a^* \left(\sum_{t=1}^T r_a^{(t)} - R_T\right) = \sum_{t=1}^T (p^*)^\top r^{(t)} - R_T$$
Thus MWU competes against the **best probability distribution $p^* \in \Delta_n$ in hindsight** with the exact same regret bound!

### 2.2 Extension 2: Rewards in $[-M, +M]$ (Width Parameter $M$)
If rewards lie in $[-M, +M]$ instead of $[-1, +1]$, dividing all rewards by $M$ normalizes them to $[-1, +1]$, and multiplying the resulting regret bound back by $M$ gives:
$$\frac{1}{T} \sum_{t=1}^T \gamma_t \ge \max_{p^* \in \Delta_n} \frac{1}{T} \sum_{t=1}^T (p^*)^\top r^{(t)} - \eta M - \frac{M \ln n}{\eta T}$$
To make the time-averaged additive error at most $\epsilon$, choose:
$$\eta = \frac{\epsilon}{2M}, \qquad T = \left\lceil \frac{4 M^2 \ln n}{\epsilon^2} \right\rceil = \mathbf{O\left(\frac{M^2 \ln n}{\epsilon^2}\right)}$$

## 3. Application 1: Solving Zero-Sum Games via MWU vs. Best Response

Instead of solving a full Linear Program, how can we compute approximate minimax strategies $(\hat{x}, \hat{y})$ for $A \in [-1, 1]^{m \times n}$?
- **Row Player** uses MWU over the $m$ rows to produce $p^{(t)} \in \Delta_m$ at round $t$.
- **Column Player** simply plays a deterministic **Best Response** column $j_t = \arg\min_{j \in \{1, \dots, n\}} (p^{(t)})^\top A^{(j)}$ (minimizing Row's payoff against $p^{(t)}$).
- After $T = \lceil \frac{4 \ln m}{\epsilon^2} \rceil$ rounds, output the **time-averaged strategies** $\hat{x} = \frac{1}{T}\sum_{t=1}^T p^{(t)}$ and $\hat{y} = \frac{1}{T}\sum_{t=1}^T e_{j_t}$:

```text
   Round t = 1..T:
   [Row Player (MWU)] ---- p^(t) ----> [Column Player (Best Response)]
          ^                                      |
          |------- reward r^(t) = A e_{j_t} -----+ (picks column j_t minimizing (p^(t))^T A e_j)
```

**Why Both $\hat{x}$ and $\hat{y}$ Are $2\epsilon$-Optimal:**
$$\min_{y \in \Delta_n} \hat{x}^\top A y \;\le\; V^* \;\le\; \max_{x \in \Delta_m} x^\top A \hat{y} \;\underbrace{\le}_{\text{MWU}} \frac{1}{T} \sum_{t=1}^T (p^{(t)})^\top A e_{j_t} + \epsilon \;\underbrace{=}_{\text{Col Best Resp.}} \frac{1}{T} \sum_{t=1}^T \min_{y_t} (p^{(t)})^\top A y_t + \epsilon \;\le\; \min_{y \in \Delta_n} \hat{x}^\top A y + \epsilon$$

## 4. Application 2: Linear Classifiers (Perceptron / Winnow via MWU)

### 4.1 Reduction to Homogeneous Non-Negative Halfspace Feasibility
Given positive points $P^+$ and negative points $P^-$ in $\mathbb{R}^{d_0}$:
1. **Absorb Intercept $b$:** Append a constant coordinate $+1$ to every point ($d_1 = d_0 + 1$).
2. **Make Weights Non-Negative ($a \ge 0$):** Replace each coordinate $z_j$ by $(+z_j, -z_j)$ ($d = 2d_1$).
3. **Unify Signs of Points:** Negate all coordinates of negative examples $P^-$.

Now we seek a non-negative weight vector $a \in \Delta_d$ ($\sum_{j=1}^d a_j = 1, a_j \ge 0$) such that:
$$a^\top x^{(i)} = \sum_{j=1}^d a_j x_j^{(i)} \ge 0 \qquad \forall i = 1, \dots, m$$
**Margin Assumption:** Suppose there exists an unknown ideal classifier $a^* \in \Delta_d$ with **margin $\epsilon > 0$**, i.e., $(a^*)^\top x^{(i)} \ge \epsilon$ for all $i = 1, \dots, m$, and all coordinates satisfy $|x_j^{(i)}| \le M$.

### 4.2 The MWU + Violated-Constraint Oracle Algorithm
- **Actions:** The $d$ coordinates $\{1, \dots, d\}$.
- **Round $t$:** MWU proposes weight vector $p^{(t)} \in \Delta_d$.
  - **Oracle Check:** Check if $(p^{(t)})^\top x^{(i)} \ge 0$ for all $i = 1, \dots, m$.
    - If **Yes**: **Terminate and return $p^{(t)}$!** (Exact separating hyperplane found!).
    - If **No**: Pick any **violated data point** $x^{(i_t)}$ with $(p^{(t)})^\top x^{(i_t)} < 0$, and feed it to MWU as the day-$t$ reward vector $r^{(t)} = x^{(i_t)} \in [-M, +M]^d$!

### 4.3 Proof of Termination in $T \le \frac{4 M^2 \ln d}{\epsilon^2}$ Rounds
Suppose the algorithm has not found a valid separator during rounds $t = 1, \dots, T$. Then:
1. **MWU's Expected Reward Every Round Is Negative:** On every round $t$, $\gamma_t = (p^{(t)})^\top r^{(t)} = (p^{(t)})^\top x^{(i_t)} < 0$, so $\frac{1}{T}\sum_{t=1}^T \gamma_t < 0$.
2. **Ideal Classifier $a^* \in \Delta_d$ Achieves $\ge \epsilon$ Every Round:** By the margin assumption, $(a^*)^\top r^{(t)} = (a^*)^\top x^{(i_t)} \ge \epsilon$ for every $t$, so $\frac{1}{T} \sum_{t=1}^T (a^*)^\top r^{(t)} \ge \epsilon$.
3. **MWU Regret Guarantee:** For $T = \lceil \frac{4 M^2 \ln d}{\epsilon^2} \rceil$, time-averaged regret is strictly less than $\epsilon$, yielding:
   $$0 > \frac{1}{T}\sum_{t=1}^T \gamma_t \ge \frac{1}{T}\sum_{t=1}^T (a^*)^\top r^{(t)} - \text{Regret} > \epsilon - \epsilon = 0 \quad \text{(Contradiction!)}$$
Thus the algorithm **must** find a valid linear separator within at most $T = O\left(\frac{M^2 \ln d}{\epsilon^2}\right)$ iterations!

## 5. Application 3: Approximate Maximum Flow via MWU + Dijkstra

Consider a unit-capacity directed network $G = (V, E)$ ($u_e = 1$) with target/optimal max-flow value $\text{OPT}$. We formulate Max-Flow / Fractional Min-Cut as a zero-sum game $A \in \{0, 1\}^{|E| \times |\mathcal{P}|}$:
- **Rows ($e \in E$):** Edges of $G$. The **Row Player (MWU)** chooses a probability distribution $x^{(t)} \in \Delta_{|E|}$ over edges (interpreted as edge lengths).
- **Columns ($P \in \mathcal{P}$):** Simple $s \leadsto t$ paths. The **Column Player (Best Response)** chooses a path $P_t \in \mathcal{P}$ minimizing $\sum_{e \in P_t} x_e^{(t)}$—which is solved in $O(m + n \log n)$ time by **Dijkstra's Shortest Path Algorithm**!
- **Payoff Entry:** $A_{e, P} = 1$ if $e \in P$ and $0$ otherwise. By LP Duality, the minimax value of this game is exactly $V^* = \frac{1}{\text{OPT}}$!

```text
   Round t = 1 .. T = O((OPT^2 log m) / ε^2):
   1. Edge Player (MWU) assigns edge probabilities/lengths x_e^(t) in Δ_|E|
   2. Path Player (Best Response) runs DIJKSTRA with edge lengths x_e^(t)
      to find shortest s -> t path P_t
   3. Edge Player updates weights: edges e on P_t get reward +1 (lengths increase!)
   4. Final Flow: Superimpose P_1, ..., P_T, each carrying (OPT / T) units of flow!
```

- **Why It Works:** Because MWU penalizes congested edges by exponentially increasing their lengths $x_e^{(t)}$, subsequent Dijkstra calls automatically route around congested edges! Averaging the $T$ paths $P_1, \dots, P_T$ (routing $\frac{(1-\epsilon)\text{OPT}}{T}$ units on each $P_t$) obeys all edge capacities and achieves a $(1-\epsilon)$-approximate maximum flow—and generalizes effortlessly to **Multicommodity Flow**!
